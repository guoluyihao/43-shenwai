# 成绩增值评价系统 PRD v1.1（评价项目版）

## 1. 背景与目标

### 1.1 背景
原系统以“全局数据”方式运行：导入一份数据后直接运行模型并在同一套页面查看结果。随着多次评价任务并存、历史回看与结果追溯需求出现，需要引入“评价项目”作为业务载体，实现数据与结果隔离管理。

### 1.2 目标
- 引入“评价项目（Project）”管理一次完整增值评价任务。
- 项目创建即上传 Excel，系统自动完成“导入 → 计算模型”，并以进度条方式展示。
- 支持后台运行（离开进度页，任务继续运行）。
- 计算中/导入中项目只允许查看进度，不允许进入详情页。
- 项目完成后提供详情页：数据计算（明细）与数据评价（班级/老师）两大能力。
- 提供“老师看板”与“学生明细矩阵”，满足老师视角查看与追溯需求。
- 保留原有导出能力，并切换为项目维度导出。
- 支持项目删除（删除项目同时清理该项目数据与上传文件）。
- UI 参考 `TaskFlow UI 设计规范 v1.0.md`，统一科技理性风格。

### 1.3 非目标（本期不做）
- 登录与权限隔离（默认单租户）。
- Excel 表头映射配置/模板管理。
- 计算任务取消、真正按步骤精确进度、任务队列并发控制。
- 项目重导入口（目前仅在“新建项目”时上传，后续可加“重导覆盖”能力）。

## 2. 用户与使用场景

### 2.1 目标用户
- 教务/年级组：导入成绩并生成增值评价结果。
- 学科/班主任：查看班级/教师维度的数据评价结果，进行导出分析。

### 2.2 核心场景（端到端）
1) 进入“评价项目列表” → 点击“新增评价项目”
2) 填写项目名称、入口考试名称、出口考试名称，并上传 Excel
3) 点击确定后跳转进度页：展示导入/计算进度，可选择后台运行
4) 计算完成后进入项目详情页：
   - 数据计算：明细、筛选、分页、导出
   - 数据评价：班级评价/老师评价、图表、筛选、导出
5) 在项目列表删除不需要的项目（非计算中项目）

## 3. 关键业务概念与数据隔离

### 3.1 业务概念
- 评价项目：一次完整评价任务，包含入口/出口考试定义、数据文件、状态与进度。
- 成绩明细：按学生-科目维度存储入口分数、本次分数以及计算结果字段。
- 评价结果：由成绩明细计算聚合得到（班级/老师维度）。

### 3.2 数据隔离策略
- 在成绩明细与统计表中增加 `project_id` 字段，所有查询/计算/导出均按 `project_id` 过滤。
- 项目删除必须清理：
  - `score_records`（project_id = X）
  - `subject_statistics`（project_id = X）
  - 上传文件 `uploads/project-X.xlsx`

## 4. 功能需求（按模块）

## 4.1 评价项目列表页

### 4.1.1 页面目标
- 展示评价项目列表及状态/进度。
- 提供新增项目入口与删除能力。
- 对于未完成项目提供“进度”入口；完成项目提供“查看”入口。

### 4.1.2 列表字段
- 项目ID
- 评价项目名称
- 入口考试名称
- 出口考试名称
- 状态（NEW/QUEUED/IMPORTING/CALCULATING/COMPLETED/FAILED）
- 进度（0~100%）
- 更新时间
- 操作（进度/查看/删除）

### 4.1.3 新增项目（弹窗）
字段（均必填）：
- 评价项目名称
- 入口考试名称
- 出口考试名称
- 上传 Excel（xlsx，固定模板）

行为：
- 提交后创建项目并保存上传文件。
- 自动触发导入与计算模型（异步）。
- 跳转到项目进度页 `/projects/{id}/progress-page`。

### 4.1.4 删除项目
- 仅允许状态非 IMPORTING/CALCULATING 的项目删除。
- 删除动作需二次确认。
- 删除后清理项目数据与上传文件。

## 4.2 项目进度页

### 4.2.1 页面目标
- 展示项目当前状态、进度、提示信息。
- 支持后台运行（离开进度页）。

### 4.2.2 行为规则
- 轮询接口 `/projects/{id}/progress`（建议 1s 一次）。
- 当状态为 QUEUED/IMPORTING/CALCULATING 时：
  - 持续轮询
  - 不显示进入详情按钮
- 当状态为 COMPLETED 时：
  - 显示进入详情按钮（进入项目详情）
- 当状态为 FAILED 时：
  - 显示失败信息 message（本期不提供重试入口）

### 4.2.3 后台运行
- “后台运行”点击后返回项目列表，不影响后台执行。

## 4.3 项目详情页（完成后可进入）

### 4.3.1 访问限制
- 项目状态 != COMPLETED 时：
  - 访问 `/projects/{id}/compute` 与 `/projects/{id}/evaluation` 必须跳转回进度页。

### 4.3.2 数据计算页（Compute）
能力：
- 明细表格展示（入口/本次分数、排名、等级、Z分数、Z赋分、差值、进退步等）。
- 支持筛选：姓名/班级/科目/教师。
- 支持手动输入“每页条数（size）”，查询后生效。
- 支持分页与导出（项目维度）。
- 点击学生姓名弹窗展示该学生在该项目下的全科明细；弹窗按进退步状态着色（进步/退步/保持）。

### 4.3.3 数据评价页（Evaluation）
结构：
- 班级评价结果 Tab
- 老师评价结果 Tab

筛选：
- 科目默认选中“总分”（班级与老师两 Tab 均默认）。
- 筛选项为平铺 chip，不使用下拉框。
- 班级/老师列表随科目变化动态联动。

列表展示（新增）：
- 班级评价与老师评价均增加两套排名（同科目、全项目范围）：
  - 实力排名：按学业综合实力降序
  - 进步率排名：按相对进步率降序
- 支持从班级/老师行下钻到“项目数据计算明细页”（带过滤参数），用于追溯学生明细范围。

图表：
- 相对进步率柱状图
- 学业综合实力柱状图
- 保持/进步/退步值柱状图

导出：
- 班级评价导出与老师评价导出（项目维度）。
- Excel 多 Sheet，按科目顺序生成：总分、语文、数学、外语、物理、化学、生物、历史、政治、地理（其余科目在后）。

### 4.3.4 老师看板（Teacher Board）
入口：
- 项目侧边栏入口：老师看板
- 路由：`/projects/{id}/teacher-board`

老师选择：
- 页面提供老师选择（平铺 chip），模拟“老师视角”进入看板（本期不做登录鉴权）。

总分老师识别规则：
- 若在该项目内存在 `subject=总分` 且 `teacher=选中老师` 的记录，则该老师为“总分老师”。

总分老师能力（班主任/总分负责人视角）：
- 选择班级（来源：该老师在“总分”科目的任教班级列表）。
- 展示本班级“总分 + 各科”的班级评价指标与排名（同科目全项目范围）。
- 提供入口下钻到“学生明细矩阵”（本班级范围）。

学科老师能力（学科视角）：
- 选择科目（来源：该老师在该项目内任教科目，排除总分）。
- 展示老师本人在该科目的老师评价指标（含两套排名）。
- 展示该科目下其任教班级的班级评价指标列表（含两套排名）。
- 提供入口下钻到“学生明细矩阵”（该老师该科目负责范围，可选班级过滤）。

### 4.3.5 学生明细矩阵（Teacher Students Matrix）
目标：
- 老师查看负责范围学生的“矩阵式”明细：纵向学生，横向科目，指标多选动态生成列。

路由：
- `GET /projects/{id}/teacher-students`

数据范围（与老师看板一致）：
- 学科老师：仅展示“本科目”列（横向科目只包含所选科目）。
- 总分老师：展示“总分 + 各科”列（横向科目为项目内学科顺序）。
- 本期不分页：全量展示老师负责范围内学生。

指标多选：
- 支持多选，选中后每个科目下生成对应列；多个指标则多列。
- 默认勾选：本次分数、进退步情况、进退步数值。

视觉与交互：
- 表头在滚动时锁定（双层表头 sticky）。
- 单元格底色按该学生该科目进退步状态着色：进步/退步/保持。
- 点击学生姓名：弹窗展示该学生“全科纵向明细”（与数据计算页一致）。

### 4.3.6 学生全科明细接口（弹窗数据）
项目维度：
- `GET /projects/{id}/students/{studentId}/subjects`：返回该学生在该项目下的全科数据（按科目顺序）。

旧版维度（不带项目隔离）：
- `GET /students/{studentId}/subjects`：返回该学生在全库的全科数据（用于旧版数据计算页弹窗）。

## 5. Excel 导入规范（固定）

### 5.1 文件要求
- 格式：xlsx
- 表头固定且必须存在：
  - 学籍号/身份证号
  - 姓名
  - 班级
  - 科目
  - 教师
  - 入口分数
  - 本次分数
- 字段不为空（本期按“数据不为空”前提处理）。

## 6. 状态机与进度

### 6.1 状态定义
- NEW：待上传（项目创建初始态）
- QUEUED：排队中（创建并提交后台任务）
- IMPORTING：导入中
- CALCULATING：计算中
- COMPLETED：已完成
- FAILED：失败

### 6.2 进度（阶段值）
以可用体验为主的阶段进度：
- QUEUED：1%
- IMPORTING：5%
- CALCULATING：35% / 55% / 90%
- COMPLETED：100%
- FAILED：100%（message 为失败原因）

## 7. 选科分类规则
- 若学生存在历史科目：历史类
- 否则若学生存在物理科目：物理类
- 否则：未分科

## 8. UI 规范要求（TaskFlow 参考）
- 颜色/阴影/渐变/字体使用 Token 化变量实现。
- 页面采用卡片化、玻璃态、主色突出、交互一致。
- 进度条、chip、按钮等组件风格统一。

## 9. 路由与接口（对齐实现）

页面：
- GET `/projects`：项目列表
- GET `/projects/{id}/progress-page`：项目进度页
- GET `/projects/{id}/compute`：数据计算（仅完成）
- GET `/projects/{id}/evaluation`：数据评价（仅完成）
- GET `/projects/{id}/teacher-board`：老师看板（仅完成）
- GET `/projects/{id}/teacher-students`：学生明细矩阵（仅完成）

操作：
- POST `/projects`：新建项目（含文件上传，自动导入与计算）
- POST `/projects/{id}/delete`：删除项目（非计算中）

接口：
- GET `/projects/{id}/progress`：返回项目状态、进度与 message
- GET `/projects/{id}/students/{studentId}/subjects`：项目内学生全科明细（用于弹窗）
- GET `/students/{studentId}/subjects`：旧版学生全科明细（用于弹窗）

导出：
- GET `/projects/{id}/export/scores`
- GET `/projects/{id}/evaluation/export?type=class|teacher`

## 10. 验收标准（核心）
- 新建项目：上传后自动导入+计算，进入进度页可见进度变化。
- 后台运行：返回列表不影响任务继续运行。
- 计算中访问详情：只能进入进度页，无法进入 compute/evaluation。
- 完成后查看：可进入数据计算与数据评价；评价科目默认总分。
- 班级/老师评价：展示两套排名（实力排名、进步率排名），排名范围为同科目全项目。
- 老师看板可用：可选择老师；总分老师可选择班级并看总分+各科；学科老师可选科目看本科目指标。
- 学生明细矩阵可用：指标多选生效；表头锁定；单元格按进退步状态着色；点击学生姓名弹窗展示全科明细。
- 数据计算页 size 可输入并生效，分页条与“每页X条”显示一致。
- 导出可用：计算与评价导出均按项目导出，评价 Sheet 顺序正确。
- 删除可用：非计算中项目可删除且数据清理。
