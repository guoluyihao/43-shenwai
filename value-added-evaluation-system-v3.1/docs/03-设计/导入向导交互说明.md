# 导入向导交互说明 v3.1

## 1. 两类导入

| 类型 | 入口 | 文档 | 结果 |
|---|---|---|---|
| 基础数据导入 | 基础数据 → 导入更新 | 学生名单、教师名单、任课安排 | 更新当前编辑稿，默认存为新版本 |
| 成绩导入 | 考试详情 → 上传/重新导入成绩 | 成绩单 | 按学校覆盖成绩，不做统计 |

文件类型统一为 **Excel（.xlsx/.xls）与 CSV**。

---

## 2. 基础数据导入

### 2.1 步骤

```
选择学校与实际年级 → 上传文档 → AI 解析 → 差异确认 → 更新确认（默认存为新版本） → 更新完成
```

### 2.2 上传

- 目标：学校 + 实际年级（如“明德中学 · 2026 届高三”）。
- 支持多文件：学生名单、教师名单、任课安排。
- 不支持手工新增/删除作为替代入口。

### 2.3 差异

| 类型 | 示例 | 处理 |
|---|---|---|
| 新增学生 | 文档有、系统无 | 确认后加入编辑稿 |
| 缺失学生 | 系统有、文档无 | 标记转出，保留历史 |
| 班级变更 | 学生换班 | 确认后更新 |
| 选科变更 | 选科组合变化 | 确认后更新 |
| 新增/变更教师 | 教师名单变化 | 确认后更新 |
| 任课/班主任变更 | 任课安排变化 | 确认后更新教师库与任课关系 |
| 低置信度 | 姓名/班级识别不确定 | 必须逐格确认 |

### 2.4 更新与版本

差异确认后，点击“更新当前编辑稿”先弹出更新确认：

- “存为新版本”默认勾选，可填写版本名称、变更说明。
- 勾选：应用差异后，把更新后的学生、班级、教师、任课关系保存为新版本；旧当前版本转“已停用”，旧版本保留。
- 取消勾选：二次确认“将覆盖当前版本 Vx”，确认后覆盖当前版本，不新增版本，原内容不可恢复。
- 当前没有已保存版本时，必须存为新版本，不能覆盖。
- 当前版本已被考试或评价任务引用时，不能覆盖，只能存为新版本。
- 更新完成后不再要求“更新后再保存版本”。
- 学生名单里的班级不存在时，自动创建班级。
- 当前编辑稿不能被考试或评价任务引用。

版本管理：

- 年级详情展示版本列表、来源、引用次数、学生数。
- 当前版本不可删除。
- 被考试或评价任务引用的版本不可删除。
- 未被引用的历史版本可由系统管理员删除；删除前确认，删除后不影响当前数据，且不可恢复。

## 3. 成绩导入

### 3.1 前置

- 考试已配置：学段、年级层次、学校、实际年级、最新已保存版本、科目。
- 只上传成绩单，不需要名册/教师/任课文档。

### 3.2 步骤

```
上传 → AI 解析 → 结果预览 → 匹配与差异 → 入库
```

### 3.3 规则

- 同一考试同一时间只允许一个导入任务。
- 可一次上传多所学校的成绩文件。
- 按学校覆盖：涉及学校替换旧成绩，未涉及学校不变。
- 入库后只保存成绩，不做平均分、排名、统计、分析。
- 导入记录保存在考试详情内。

### 3.4 差异

| 级别 | 示例 | 处理 |
|---|---|---|
| 阻断 | 无法识别学生、重复、越界、文件损坏 | 逐条处理，清零后入库 |
| 待确认 | 新增/缺失学生、班级变更、选科变更、赋分缺失 | 逐条或批量确认 |
| 提示 | 低置信度、科目别名、格式不统一 | 批量接受 |

---

## 4. 空态与异常

| 场景 | 表现 |
|---|---|
| 学校无实际年级 | 新增考试时不可选 |
| 实际年级无已保存版本 | 新增考试时不可选 |
| 编辑稿未保存 | 考试/评价不可引用，显示提示 |
| 已有导入任务 | 阻止新任务 |
| 文件为空/损坏 | 阻断并提示 |
| 低置信度 | 高亮，必须人工确认 |
