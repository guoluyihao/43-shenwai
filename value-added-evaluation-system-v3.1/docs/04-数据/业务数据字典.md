## 2. 年级

| 字段 | 说明 |
|---|---|
| 实际年级名称 | 如“2026 届高三”，同校唯一 |
| 学段 | 高中 / 初中 |
| 年级层次 | 高一/高二/高三，初一/初二/初三 |
| 入学年份 | |
| 状态 | 在读 / 已毕业 |

- 实际年级 = 学校 + 学段 + 年级层次 + 入学年份。
- 考试先选学段、年级层次，再自动匹配学校实际年级。

## 3. 年级版本

| 字段 | 说明 |
|---|---|
| 版本号 | V1、V2…… |
| 所属学校 / 实际年级 | |
| 版本名称 | 如“分班后”“高三调整后” |
| 状态 | 已保存 / 已停用 |
| 来源 | 导入生成 / 手动保存 / 覆盖 |
| 保存时间 / 保存人 | |
| 变更说明 | 必填 |
| 被引用 | 被考试、评价任务引用的次数 |

规则：

- 基础数据更新默认存为新版本：更新后的学生、班级、教师、任课关系生成新版本，旧当前版本转“已停用”。
- 取消“存为新版本”时，必须二次确认覆盖当前版本；覆盖后不新增版本，原内容不可恢复。
- 当前没有已保存版本时，必须存为新版本。
- 当前版本已被考试/评价任务引用时，不能覆盖，只能存为新版本。
- 手动“保存版本”作为备份当前数据的入口。
- 考试和评价只引用已保存版本。
- 当前版本不可删除；被考试/评价引用的版本不可删除；未被引用的历史版本可由系统管理员删除。
- 删除版本不影响当前数据，删除后不可恢复。

## 14. 结果

学生结果：学号、姓名、学校、班级、科目/总分、入口/评价、等级变化、进退步、联考排名。

班级/教师/学校结果：人数、学业实力、保持值、进步值、退步值、相对进步率、平均进退步、进步/退步占比、两套排名。教师结果还包含任教班级；学生结果包含联考排名。

- 班级/教师：校内排名。
- 学校：联考排名。
- 学校指标与班级完全一致。
