# 增值评价算法说明 v3.1（公开版）

> 一份面向所有读者的完整算法说明：从“为什么不能直接比分数”，到标准分、9 档等级、权重、判定、四层汇总，再到完整的学生/班级示例。
>
> **公开版说明**：本文档中的学生、班级、分数、排名均为虚构示例，不对应任何真实个人或学校。真实任务数据只在登录后的评价任务 → 结果 → 计算过程中查看。
>
> 当前默认：**9 档**；档位支持自定义配置。

---

## 0. 先看这一页：业务语言总结

增值评价不是看“这次考了多少分”，而是看“从入口到出口，学生在同类学生中是前进了、停住了，还是后退了”。

### 0.1 一句话流程

```text
入口位置 → 出口位置 → 位置变化 → 等级 → 权重 → 班级/学校指标
```

### 0.2 用业务话解释

| 业务问题 | 算法怎么回答 |
|---|---|
| 两次考试难度不同，怎么比？ | 不比绝对分，比“在联考全体中的位置”。 |
| 位置怎么表示？ | 用标准分 z，可以理解为“比平均高/低几个身位”。 |
| 位置变化怎么判断？ | 评价 z 减入口 z，变化很小算保持，上升算进步，下降算退步。 |
| 为什么要分九等级？ | 把连续位置分成 G1–G9，方便解释前段、中间、后段。 |
| 权重是什么？ | 不是分数、不是占比，是每个等级对应的“位置分”：G1=90，G9=10。 |
| 权重有什么用？ | 把等级变成可相加、可平均的数，用来算学业实力、保持值、进步值、退步值。 |
| 学校/班级结果看什么？ | 看学业实力、保持值、进步值、退步值、相对进步率，不能只看一个排名。 |
| 用结果要注意什么？ | 先看样本和异常，再看指标；小样本不排名；不同参数/版本不能直接比。 |

### 0.3 三句话记住

1. **入口出口比位置，位置变化看进步。**
2. **等级换成权重，权重汇成班级和学校。**
3. **先看样本和异常，再看指标和排名。**

### 0.4 数据口径也要看

- 每科逐条成绩优先赋分，赋分缺失才回退原始分；
- Z 限幅到 `[-3.1, 3.1]`，每个排名组第一名固定 3.1；
- 等级按 Z 区间，不按人数比例强制切；
- 部分缺考由任务参数决定：整生剔除或仅剔除该科；
- 小样本：班级/教师少于 8 人不排名。

## 1. 这份文档解决什么问题

增值评价要回答的不是“这次考了多少分”，而是：

> 相对于入口考试，学生在联考全体中的位置是上升了、保持了，还是下降了？这种变化如何汇总到班级、教师和学校？

直接比较两次考试的分数不可靠，因为：

- 两次试卷难度不同；
- 两次阅卷尺度可能不同；
- 两次参加考试的学生群体可能不同；
- 不同科目的满分、平均分、标准差不同。

所以要先标准化，再比较位置变化。

---

## 2. 核心概念

| 概念 | 用大白话解释 | 在计算中做什么 |
|---|---|---|
| 入口考试 | 作为起点的考试 | 提供入口分数、排名、等级 |
| 评价考试 | 作为终点的考试 | 提供评价分数、排名、等级 |
| 联考全体 | 参加本次评价的全部可比学生 | 标准分和排名的比较总体 |
| 标准分 z | “比平均高几个标准差” | 把不同科目、不同难度放到同一把尺子上 |
| 等级 | 按标准正态 Z 区间划成 G1–G9 | 把连续标准分变成离散档位 |
| 权重 | 每个等级对应的“位置分” | 把等级转换成可汇总的数值 |
| 贡献 | 一个学生给班级指标增加了多少 | 保持、进步、退步分别累加 |
| 四层汇总 | 学生 → 班级 → 教师 → 学校 | 用同一套指标逐层汇总 |

### 2.1 为什么要分物理类/历史类

物理类和历史类的总分构成、竞争群体不同：

- 物理类：语文 + 数学 + 外语 + 物理 + 2 门再选；
- 历史类：语文 + 数学 + 外语 + 历史 + 2 门再选。

总分必须在同首选组内标准化；单科仍在联考全体同科目内标准化。

## 3. 权重专章：权重是什么、为什么有、怎么用

### 3.1 权重是什么

**权重不是学生得分，不是概率，也不是占比。**

权重是等级的位置分：学生被划到某个等级后，用这个等级对应的数字代表他的位置。G1 最好，权重 90；G9 最弱，权重 10。

为什么要多此一举？因为“等级”是离散的，不能直接做加减平均。把 G1–G9 映射成 90–10 之后，才能计算：

- 平均学业实力；
- 保持贡献；
- 进步贡献；
- 退步贡献。

> 关键顺序：先算 z → 限幅并处理第一名 → 按 Z 区间划等级 → 最后才取权重。权重不参与标准分，也不参与等级划分；它只在等级确定之后参与汇总。

### 3.2 9 档 Z 区间、理论占比与权重

| 等级 | Z 区间 | 理论占比 | 权重 |
|---|---|---:|---:|
| G1 | Z > 1.75 | 4% | 90 |
| G2 | 1.25 < Z ≤ 1.75 | 6.5% | 80 |
| G3 | 0.75 < Z ≤ 1.25 | 12.1% | 70 |
| G4 | 0.25 < Z ≤ 0.75 | 17.5% | 60 |
| G5 | -0.25 < Z ≤ 0.25 | 19.8% | 50 |
| G6 | -0.75 < Z ≤ -0.25 | 17.5% | 40 |
| G7 | -1.25 < Z ≤ -0.75 | 12.1% | 30 |
| G8 | -1.75 < Z ≤ -1.25 | 6.5% | 20 |
| G9 | Z ≤ -1.75 | 4% | 10 |

**等级按 Z 区间判定，不按人数比例直接切。**理论占比来自标准正态分布，实际人数可能偏离；**9 档对应 9 个权重。**档位支持自定义配置：新增或调整档位时，必须同步配置 Z 边界与权重，并生成新的结果版本；不同档位配置的结果不能直接比较。

### 3.3 为什么是 90 到 10，而不是 100 到 0

- 最高 90、最低 10，保留上下空间，避免“满分/零分”带来极端值；
- 每档相差 10 分，等级之间的差距直观、可解释；
- G1 与 G9 相差 80 分，足以拉开位置差异，又不会让某一档完全压倒其他指标；
- 权重是业务设计参数，不是统计推导出来的；改变权重会改变班级/学校排名，必须固定口径并版本化。

### 3.4 权重的三个用途

| 用途 | 取哪个权重 | 说明 |
|---|---|---|
| 学业实力 | 本次评价等级权重 | 评价等级越高，贡献越大 |
| 保持贡献 | 入口等级权重 − 10 | 只统计保持学生 |
| 进步贡献 | 从入口等级向上跨级经过的权重 | 只统计进步学生 |
| 退步贡献 | 从入口等级向下跨级经过的 `100 − 权重` | 只统计退步学生 |

### 3.5 一个学生的权重账本

以虚构学生 X 为例：入口 G3（权重 70），评价 G5（权重 50），判定退步 2 级。

```text
学业实力贡献：取评价等级权重 = 50
保持贡献：不适用（不是保持）
进步贡献：不适用（不是进步）
退步贡献：
  G3 → G4：100 − 60 = 40
  G4 → G5：100 − 50 = 50
  合计：90
```

如果学生 B 入口 G2（80），评价 G3（70），退步 1 级：退步贡献 = 100 − 70 = 30。

如果学生 C 入口 G3（70），评价 G2（80），进步 1 级：进步贡献 = G2 的权重 80。

> 注意：“学业实力”取的是评价等级权重；“保持/进步/退步”取的是入口到评价之间的跨级权重，不是简单把入口权重和评价权重相减。退步用 100 减目标等级权重，是为了让“退得越深，贡献越大”。

### 3.6 常见误读

- 把权重当成学生得分；
- 把权重当成概率或百分比；
- 不同档位配置之间混用权重；
- 把“学业实力”当成平均分；
- 把“相对进步率”当成百分比。

## 4. 从原始分到标准分

### 4.1 要解决什么问题

语文、数学、英语满分可能都是 150，但各科平均分和标准差不同。同样是“比平均高 10 分”，在不同科目里的含金量不同。标准分用“高出几个标准差”统一尺度。

### 4.2 公式

```text
z =（x − μ）÷ σ
```

文字解释：

- `x`：这个学生在该科目/组的采用值；
- `μ`：联考全体该科目/组的平均分；
- `σ`：联考全体该科目/组的标准差，反映大家分数有多分散；
- `z=0`：正好在平均位置；
- `z=1`：比平均高一个标准差；
- `z=-1`：比平均低一个标准差。

入口、评价各算一次：

```text
Δz = 评价 z − 入口 z
```

Δz 为正，说明相对位置上升；为负，说明相对位置下降；接近 0，说明位置基本没变。

**限幅与第一名：**原始 z 算完后，统一截断到 **[-3.1, 3.1]**；每个排名组的第一名，z 固定为 **3.1**；第二名及以下使用原始 z 限幅后的值。这样极端值不会无限放大，同时保留第一名的区分度。

> 说明：核对文档未给出“第二名及以下用等级和总分折算 Z”的具体插值公式；当前实现采用“原始 z 限幅”的可执行规则。若后续提供正式折算公式，应替换并重算。

### 4.3 代入示例

虚构学生 A 的语文：入口 92 分，联考均值 90，标准差 10。

```text
入口 z =（92 − 90）÷ 10 = 0.20
```

评价 95 分，联考均值 91，标准差 9.5。

```text
评价 z =（95 − 91）÷ 9.5 = 0.42
Δz = 0.42 − 0.20 = 0.22
```

0.22 小于保持阈值 0.25，所以语文判定“保持”。这不是说分数没变，而是说相对位置变化很小。

### 4.4 总分

```text
总分 = 六科采用值之和
```

- 每科逐条成绩优先取赋分；该条赋分为空时，回退原始分；
- 语文、数学、外语、物理、历史通常没有赋分，因此使用原始分；
- 化学、生物、政治、地理通常有赋分，赋分缺失的个别记录回退原始分并标注；
- 总分按物理类/历史类分别标准化。

## 5. 从标准分到等级

### 5.1 为什么要划等级

标准分是连续小数，不直观；等级把位置变成 G1–G9，方便解释“前 10%”“中间”“后段”，也方便用权重汇总。

### 5.2 按 Z 区间划等级

等级不看人数比例，而看 z 落在哪个标准正态区间：

```text
Z > 1.75 → G1
1.25 < Z ≤ 1.75 → G2
0.75 < Z ≤ 1.25 → G3
0.25 < Z ≤ 0.75 → G4
-0.25 < Z ≤ 0.25 → G5
-0.75 < Z ≤ -0.25 → G6
-1.25 < Z ≤ -0.75 → G7
-1.75 < Z ≤ -1.25 → G8
Z ≤ -1.75 → G9
```

4%、6.5%、12.1% 等是标准正态下的**理论占比**，不是强制切分比例；实际人数可能偏离。

示例：

- 学生 A 总分入口 z=0.53，落在 G4；
- 评价 z=0.65，仍在 G4。

### 5.3 排名范围

| 对象 | 排名范围 |
|---|---|
| 学生单科 | 联考全体同科目 |
| 学生总分 | 同首选组（物理类/历史类） |
| 班级 | 校内同年级 |
| 教师 | 校内同科目 |
| 学校 | 联考全体 |

> 范围不同，不能直接把“校内第 1”与“联考第 1”混为一谈。

## 6. 从等级到判定

### 6.1 为什么需要阈值

位置小幅波动是正常的，不应该都算进步或退步。保持阈值就是“允许波动的安全带”：|Δz| 不超过阈值，判定保持。

```text
|Δz| ≤ 0.25 → 保持，级数 0
Δz > 0.25 → 进步
Δz < −0.25 → 退步
```

### 6.2 级数

```text
进步级数 = 1 + floor((Δz − 0.25) ÷ 0.5)
退步级数 = −(1 + floor((|Δz| − 0.25) ÷ 0.5))
```

文字解释：超过阈值后，每多 0.5 个标准差，多算一级。

- Δz=0.55：进步级数 = 1 + floor((0.55−0.25)/0.5) = 1 级；
- Δz=-0.56：退步级数 = -(1 + floor((0.56−0.25)/0.5)) = -1 级。

### 6.3 虚构学生 A 的判定

- 总分 Δz=0.12，|Δz| ≤ 0.25，保持，0 级；
- 历史 Δz=-0.56，退步 1 级；
- 地理 Δz=0.55，进步 1 级；
- 语文、数学、英语、政治均在阈值内，保持。

> 级数不是分数：级数表示跨了几级，不直接等于权重；权重贡献要按第 3 章的跨级规则取。

### 6.4 等级差法

```text
级数 = 入口等级 − 评价等级
```

正数为进步，负数为退步，0 为保持。

## 7. 四层汇总

### 7.1 为什么不能直接平均等级

等级是离散的，直接平均 G1–G9 会丢失“档位间距”的信息；而且保持、进步、退步需要分别表达。权重提供了统一的数值尺度。

### 7.2 指标公式与文字解释

```text
学业实力 = Σ（本次等级权重）÷ 人数
```

把每个学生评价等级对应的权重加起来，除以人数。数值越高，说明这个群体整体位置越靠前。

```text
保持值 = Σ（入口等级权重 − 10）÷ 人数
```

只统计判定为保持的学生。入口 G2 权重 80，保持贡献 70；入口 G3 权重 70，保持贡献 60。

```text
进步值 = Σ（进步跨级权重）÷ 人数
```

只统计进步学生。G3→G2 贡献 80；G3→G1 贡献 80+90=170。

```text
退步值 = Σ（100 − 退步目标等级权重）÷ 人数
```

只统计退步学生。G3→G4 贡献 40；G3→G5 贡献 40+50=90。

```text
相对进步率 =（保持值 + 进步值×2）÷（（退步值+1）×1.5）
```

这是一个业务合成指标，不是百分比：分子奖励保持和进步，进步乘 2 表示更鼓励进步；分母对退步做放大，加 1 和乘 1.5 是为了避免除零并体现退步代价。它不是数学推导出来的，改变参数会改变排名。

```text
平均级数 = Σ级数 ÷ 人数
```

正数表示平均进步，负数表示平均退步。

### 7.3 班级/教师/学校的关系

- 班级：按当前班级汇总，校内排名；
- 教师：按“教师 × 科目”汇总，校内同科目排名；未匹配教师的成绩不进入教师结果；
- 学校：按学校汇总，联考全体排名；指标公式与班级一致；
- 小样本：班级/教师人数少于 **8 人**时只展示指标，不排名。

### 7.4 单校与多校

- 单校评价是多校联考的特例：联考全体 = 本校全体；
- 多校评价时，所有学校放在同一总体内标准化，学校结果才有比较意义；
- 不支持“每校各自标准化后直接比较学校”，该口径会使学校结果失真。

## 8. 学生完整示例（虚构数据）

> 学生 A · 学号 S-A01 · 示例班级 C01 · 历史类。以下数据全部为虚构。

| 科目 | 入口分 | 入口均值 | 入口标准差 | 入口 z | 入口排名 | 入口等级 | 评价分 | 评价均值 | 评价标准差 | 评价 z | 评价排名 | 评价等级 | Δz | 判定 | 级数 |
|---|---:|---:|---:|---:|---:|---|---:|---:|---:|---:|---:|---|---:|---|---:|
| 语文 | 92.00 | 90.00 | 10.00 | 0.20 | 600 | G5 | 95.00 | 91.00 | 9.50 | 0.42 | 570 | G4 | 0.22 | 保持 | 0 |
| 数学 | 78.00 | 70.00 | 15.00 | 0.53 | 800 | G4 | 82.00 | 74.00 | 14.00 | 0.57 | 780 | G4 | 0.04 | 保持 | 0 |
| 英语 | 105.00 | 95.00 | 12.00 | 0.83 | 400 | G3 | 108.00 | 98.00 | 12.00 | 0.83 | 380 | G3 | 0.00 | 保持 | 0 |
| 历史 | 80.00 | 72.00 | 9.00 | 0.89 | 200 | G3 | 76.00 | 73.00 | 9.00 | 0.33 | 450 | G4 | -0.56 | 退步 | -1 |
| 政治 | 76.00 | 70.00 | 10.00 | 0.60 | 300 | G4 | 80.00 | 72.00 | 10.00 | 0.80 | 250 | G3 | 0.20 | 保持 | 0 |
| 地理 | 68.00 | 70.00 | 9.00 | -0.22 | 870 | G5 | 74.00 | 71.00 | 9.00 | 0.33 | 700 | G4 | 0.55 | 进步 | +1 |
| **总分** | **499.00** | 470.00 | 55.00 | 0.53 | 300 | G4 | **515.00** | 480.00 | 54.00 | 0.65 | 280 | G4 | 0.12 | 保持 | 0 |

### 8.1 逐步代入

```text
入口总分 z =（499 − 470）÷ 55 = 0.53
评价总分 z =（515 − 480）÷ 54 = 0.65
总分 Δz = 0.65 − 0.53 = 0.12
|0.12| < 0.25 → 保持，级数 0
```

### 8.2 权重账本

学生 A 总分入口 G4、评价 G4：

- 评价权重 60，进入班级“学业实力”求和；
- 保持贡献 = 60−10 = 50，进入“保持值”求和。

### 8.3 怎么读

学生 A 总分保持，但历史退步 1 级、地理进步 1 级；语文/数学/英语/政治在阈值内保持。不能只看总分，也不能只看单科。

| S-A05 | G5 | G5 | 保持 | 0 | 50 | 40 | 0 | 0 |
| S-A06 | G1 | G1 | 保持 | 0 | 90 | 80 | 0 | 0 |
| S-A07 | G3 | G5 | 退步 | -2 | 50 | 0 | 0 | 90 |
| S-A08 | G2 | G3 | 退步 | -1 | 70 | 0 | 0 | 30 |
| S-A09 | G4 | G4 | 保持 | 0 | 60 | 50 | 0 | 0 |
| S-A10 | G5 | G4 | 进步 | +1 | 60 | 0 | 60 | 0 |
| **合计** |  |  |  | **-2** | **650** | **290** | **130** | **160** |

### 9.1 汇总公式代入

```text
人数 n = 10
学业实力 = 650 ÷ 10 = 65.00
保持值 = 290 ÷ 10 = 29.00
进步值 = 130 ÷ 10 = 13.00
退步值 = 160 ÷ 10 = 16.00
相对进步率 =（29 + 13×2）÷（（16+1）×1.5）= 55 ÷ 25.5 = 2.16
平均级数 = -2 ÷ 10 = -0.20
```

### 9.2 逐项解释

- **学业实力 65.00**：10 个评价权重之和 650，平均每个学生 65 分位置分；不是平均分 65 分。
- **保持值 29.00**：5 名保持学生贡献 50+70+40+80+50=290，平均 29。
- **进步值 13.00**：2 名进步学生贡献 70+60=130，平均 13。
- **退步值 16.00**：3 名退步学生贡献 40+90+30=160，平均 16。
- **相对进步率 2.16**：保持和进步贡献明显高于退步贡献；这是合成指标，不是 216%。
- **平均级数 -0.20**：平均每人退步 0.2 级；与相对进步率方向不完全一致，因为两者口径不同。

## 10. 结果怎么读

### 10.1 四个指标分别回答什么

- 学业实力：这个群体整体位置靠前还是靠后；
- 保持值：有多少人稳住了原有位置；
- 进步值：有多少人向上移动、移动了多少；
- 退步值：有多少人向下移动、移动了多少；
- 相对进步率：把三类贡献合成一个可比较的指数。

### 10.2 常见误读

- 把“学业实力 66”当成平均分 66；
- 把“相对进步率 2.16”当成 216%；
- 只看相对进步率，不看保持/进步/退步结构；
- 用小样本班级的排名下结论；
- 拿不同档位、不同版本的结果直接比较；
- 把校内排名当成联考排名。

## 11. 参数、版本与边界

### 11.1 参数配置

系统管理员可以维护新建任务的默认参数：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| 等级档数 | 9 档 | 当前预设 9 档；档位支持自定义配置 |
| 保持阈值 | 0.25 | 标准分法判定保持 |
| 每级步长 | 0.5 | 进步/退步级数 |
| 小样本阈值 | 8 人 | 班级/教师不排名阈值 |
| 部分缺考处理 | 整生剔除 | 可切换为“仅剔除该科” |
| 默认算法 | 标准分法 | 新建任务默认算法 |

- “整生剔除”：任一科缺考，该生不进入该任务任何统计；
- “仅剔除该科”：缺考科不参与，其他科仍保留；
- 参数只影响新建任务；
- 已完成任务保留自己的参数和结果快照；
- 需要改变已完成任务的口径时，应新建任务并重新计算。

### 11.2 结果版本

每次计算生成一个结果版本，参数、样本、结果在同一版本内一致。不同版本、不同档数的结果不能直接混用。

### 11.3 边界规则

| 情形 | 处理规则 |
|---|---|
| 单科缺考 | 由任务参数决定：整生剔除，或仅剔除该科、其他科保留；总分始终要求六科完整 |
| 赋分缺失 | 逐条成绩优先赋分；该条赋分缺失时回退原始分并标注 |
| 两场未满六科 | 进入学生异常清单，不进入总分样本 |
| 外语语种变更 | 总分不可比，单独列入异常 |
| 班级变更 | 按评价考试当前班级归属；入口班级仅用于识别 |
| 教师未匹配 | 成绩不进入教师结果，单独列入成绩异常 |
| 小样本 | 班级/教师人数少于 **8 人**只展示指标，不排名 |
| 学校单边参与 | 只计算共同学校，单边学校列入异常 |

## 12. 常见指标问题

> 示例均使用“某校/某班/某次任务”的通用数据，不对应真实对象。

### A. 指标含义

| 问题 | 结论 |
|---|---|
| 相对进步率为什么都是正数？ | 公式是非负比值；分子、分母都不会为负，正数不代表“进步”，要看相对 1 的位置。 |
| 相对进步率大于 1 是什么意思？ | 保持和进步的加权贡献大于退步；1 是平衡点，不是 100%。 |
| 相对进步率为什么不是百分比？ | 它是加权比值，不是占比或增长率。 |
| 学业实力是平均分吗？ | 不是；它是评价等级权重的平均值，表示整体位置。 |
| 权重是分数或占比吗？ | 都不是；权重是等级的位置分，G1=90，G9=10。 |
| 为什么权重是 90 到 10？ | 业务设计的等级位置分；保留上下空间，每档差 10，便于解释和汇总。 |
| 9 档为什么对应 9 个权重？ | 等级数和权重数必须一一对应，不能拿其他档位权重套用。 |

### B. 平均级数

| 问题 | 结论 |
|---|---|
| 平均级数是什么意思？ | 所有学生级数之和 ÷ 人数；正数净进步，负数净退步，0 净持平。 |
| 平均级数为什么接近 0？ | z 分是内部标准化的，平均 Δz 接近 0，级数正负抵消后也接近 0。 |
| 平均级数接近 0，是不是没人进步？ | 不是；进步和退步可能互相抵消，要看人数和分布。 |
| 平均级数和相对进步率有什么区别？ | 平均级数看净跨级幅度；相对进步率看加权贡献的比值。 |
| 平均级数为负，但相对进步率大于 1，矛盾吗？ | 不矛盾；一个看净级数，一个看加权贡献比。 |

### C. 联考整体

| 问题 | 结论 |
|---|---|
| 联考整体的平均级数有意义吗？ | 作为“整体教育质量”意义很弱；适合比较学校/班级等子群体。 |
| 为什么联考整体平均级数会趋于 0？ | 同一批学生内部标准化，平均位置变化接近 0；不是算法错误。 |
| 为什么几所学校的语文相对进步率都是正数、甚至都大于 1？ | 指标不是零和的；各校加权贡献都大于退步时，就可能都大于 1。 |
| 为什么学校之间的相对进步率不能直接相加？ | 它是比值，不是份额；相加没有业务意义。 |
| 为什么平均级数接近 0，但学校相对进步率都大于 1？ | 两者口径不同；相对进步率是非负加权比值，还带 +1 和 ×1.5 的缩放。 |

### D. 样本与剔除

| 问题 | 结论 |
|---|---|
| “名册内剔除人数”是怎么来的？ | 当前名册人数 − 可计算样本人数；具体人数随任务和数据变化。 |
| 名册内剔除和全部异常学生有什么区别？ | 名册内剔除只统计当前名册；全部异常还会包含仅入口、仅评价等不在当前名册的学生。 |
| 为什么仅入口学生不计入名册内剔除？ | 仅入口不在当前名册；计入会导致“可计算样本 + 名册内剔除 ≠ 当前名册人数”。 |
| 部分缺考人数和名册内剔除人数是什么关系？ | 部分缺考是名册内剔除的原因之一；还包括仅评价、语种变更、无成绩、选科不足等。 |
| 单科缺考到底怎么处理？ | 由任务参数决定：整生剔除，或仅剔除该科；当前示例任务使用整生剔除。 |
| 赋分优先是什么意思？ | 逐条成绩有赋分用赋分，没有赋分才回退原始分。 |
| 物理/历史为什么没有赋分？ | 当前源表没有两科赋分；规则仍保留，未来有赋分会优先使用。 |
| 小样本到底少于多少不排名？ | 少于 8 人；只展示指标，不参与排名。 |

### E. 算法细节

| 问题 | 结论 |
|---|---|
| 为什么 Z 要限幅到 [-3.1, 3.1]？ | 防止极端值无限放大；第一名固定 3.1，第二名及以下用原始 z 限幅。 |
| 为什么第一名是 3.1，不按公式算？ | 核对文档的规则；保留第一名的区分度并控制极端值。 |
| 等级按 Z 区间还是排名百分位？ | 按 Z 区间；4%、6.5% 等是理论占比，不是强制切分比例。 |
| 为什么理论占比和实际人数不一样？ | 实际数据不一定完全符合标准正态。 |
| 0.25 是保持还是进步？ | `|Δz| ≤ 0.25` 保持；`> 0.25` 进步；`< -0.25` 退步。 |
| 标准分法和等级差法有什么区别？ | 标准分法比较 z 变化；等级差法直接比较入口和评价等级。 |
| 为什么同分学生排名一样？ | 同分同名次；等级仍按 Z 区间判定。 |

### F. 结果解读

| 问题 | 结论 |
|---|---|
| 学生分数提高了，为什么还是退步？ | 看相对位置；如果整体提高更多，个人位置可能下降。 |
| 为什么总分和单科等级不一致？ | 单科按联考同科目排名，总分按同首选组排名，比较群体不同。 |
| 为什么班级/教师和学校排名不同？ | 班级/教师按校内排名，学校按联考全体排名。 |
| 为什么小样本还显示指标？ | 指标可以看但不排名，避免人数少导致排名不稳定。 |
| 为什么不同档位、不同版本不能直接比较？ | 参数和结果快照不同，必须在同一口径下重算后再比较。 |
| 为什么结果页小数和计算过程略有差异？ | 展示四舍五入导致；判定使用未四舍五入的值。 |
| 赋分回退后还能比较吗？ | 可以计算，但混合原始分/赋分会影响可比性，需要看回退标记。 |

### G. 同类补充

| 问题 | 结论 |
|---|---|
| 保持值、进步值、退步值是人数或百分比吗？ | 都不是；是按等级权重计算的学生平均贡献。 |
| 学业实力高，等于进步大吗？ | 不等于；一个看当前整体位置，一个看位置变化。 |
| 相对进步率高，等于退步人数少吗？ | 不等于；它是加权比值，不是退步人数占比。 |
| 为什么某科相对进步率高，平均级数却可能为负？ | 一个看净级数，一个看加权贡献比，口径不同。 |
| 平均级数和平均等级是一回事吗？ | 不是；平均等级看当前位置，平均级数看变化幅度。 |
| 为什么不能拿其他档位的权重套用？ | 档位和权重必须一一对应，混用会让等级和汇总失真。 |
| 修改参数后，旧任务结果为什么不变？ | 旧任务保留自己的参数和结果快照；参数只影响新建任务。 |
| 重新计算为什么要生成新版本？ | 保证参数、样本、结果在同一版本内一致，便于追溯。 |

## 13. 术语表

| 术语 | 含义 |
|---|---|
| z | 标准分，表示相对联考均值的位置 |
| Δz | 评价 z 减入口 z，表示位置变化 |
| 等级 | 按标准正态 Z 区间划分的 G1–G9 |
| 权重 | 等级对应的位置分，9 档为 90–10 |
| 学业实力 | 评价等级权重的平均值 |
| 保持值 | 保持学生的入口权重减 10 的平均 |
| 进步值 | 进步学生跨级权重的平均 |
| 退步值 | 退步学生 `100 − 目标等级权重` 的平均 |
| 相对进步率 | 保持、进步、退步贡献的合成指标 |
| 结果版本 | 参数、样本、结果一致的快照 |
