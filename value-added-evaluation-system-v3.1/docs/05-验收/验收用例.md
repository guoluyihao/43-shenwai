# 验收用例 v3.1

> 本期原型已完成基础数据、成绩数据与评价任务（四类结果）；A02/A03/A05 等导入交互用例为完整版验收，导入向导当前未开放。

## 一、基础数据

| # | 操作 | 预期 |
|---|---|---|
| A01 | 基础数据页面 | 系统管理员先看到学校列表，再进入年级列表；只有年级/教师，无科目管理；年级列表有“新增年级” |
| A02 | 导入学生名单 | AI 解析、差异确认、更新确认；默认勾选“存为新版本” |
| A03 | 导入教师名单/任课安排 | 教师、班主任、科任更新 |
| A04 | 勾选“存为新版本”更新 | 更新后生成新版本，旧当前版本转已停用，旧版本保留 |
| A05 | 取消“存为新版本” | 二次确认提示将覆盖当前版本 Vx；确认后不新增版本，覆盖当前版本；被引用版本不允许覆盖 |
| A06 | 当前无已保存版本 | 必须存为新版本，不能覆盖 |
| A07 | 未保存编辑稿 | 考试不能引用 |
| A08 | 检查基础数据入口 | 无独立新增/删除按钮 |
| A09 | 教师单列 | 教师列表含学科、班级、是否班主任 |
| A10 | 删除版本 | 当前版本、被引用版本不可删；未被引用历史版本可删，删除不影响当前数据 |

## 二、考试管理

| # | 操作 | 预期 |
|---|---|---|
| B01 | 新增考试选学段 | 只显示该学段学校；必须点击“选择学校”，不默认展示或勾选学校 |
| B02 | 选年级层次 | 只显示有该层次实际年级的学校 |
| B03 | 选学校 | 自动带出实际年级与最新已保存版本 |
| B04 | 科目选择 | 只能选学段固定科目 |
| B05 | 上传成绩单 | 解析、匹配、差异确认、入库 |
| B06 | 重复导入 | 按学校覆盖，未涉及学校不变；已完成评价结果不变 |
| B07 | 同时发起两个导入 | 第二个被拒绝 |
| B08 | 考试详情 | 只有成绩与导入记录，无统计 |
| B09 | 删除有任务考试 | 被拒绝 |

## 三、评价任务

| # | 操作 | 预期 |
|---|---|---|
| C01 | 新建任务 | 可选入口/评价考试 |
| C02 | 按校选版本 | 列出已保存/已停用版本，默认取评价考试版本；已停用版本标注“历史” |
| C03 | 两场考试学校不一致 | 只算共同学校，单边进异常 |
| C04 | 阻断未处理 | 不能进入算法 |
| C05 | 标准分法 | 按联考全体标准化 |
| C06 | 等级差法 | 按联考全体等级差 |
| C07 | 计算完成 | 参数参与计算，生成四类结果与新结果版本 |
| C08 | 入口/评价版本不一致 | 进入异常清单，确认后继续 |

## 四、结果

| # | 操作 | 预期 |
|---|---|---|
| D01 | 学生结果 | 展示联考排名/等级/进退步，可切科目 |
| D02 | 班级结果 | 校内排名，含进步占比、退步占比等完整指标 |
| D03 | 教师结果 | 校内排名，含任教班级、进步占比等完整指标 |
| D04 | 学校结果 | 联考排名，含退步占比，指标与班级一致 |
| D05 | 结果入口 | 只能从评价任务进入 |
| D06 | 结果页面 | 只有四张表，无图表/报告/看板/矩阵 |
| D07 | 样本不足 | 标注不排名 |
| D08 | 赋分缺失 | 逐条回退并标注 |
| D09 | 导出当前结果 | 生成 CSV 文件，字段与当前 Tab 一致 |

## 五、权限与菜单

| # | 操作 | 预期 |
|---|---|---|
| E01 | 学校管理员登录 | 只读，仅本校 |
| E02 | 尝试导入/新增/删除 | 无入口或被拒绝 |
| E03 | 系统管理员菜单 | 学校管理、基础数据、考试管理、评价任务 |
| E04 | 学校管理员菜单 | 基础数据、考试管理、评价任务 |
| E05 | 登录落地 | 评价任务 |
| E06 | 检查旧菜单 | 无工作台、独立版本、独立导入记录、独立结果菜单 |
| E07 | 检查列表页 | 学校/考试/评价任务列表不展示无意义统计卡 |

## 六、通过标准

- 科目按学段写死，无科目管理。
- 基础数据只能导入更新；更新默认存为新版本，取消勾选则覆盖当前版本；未引用历史版本可删除。
- 新增考试按学段→年级层次→学校，自动带出实际年级与最新版本。
- 成绩按校覆盖，单任务。
- 评价按联考全体计算，四类结果表格。
- 学校管理员只读。
- 无控制台报错、无死链。
