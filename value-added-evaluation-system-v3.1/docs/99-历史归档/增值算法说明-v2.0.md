# 增值算法说明 v2.0

> 本文只讲业务口径，不涉及代码实现。算法参数可在评价任务中配置并随结果版本固化。

## 1. 共同前置

1. 只使用匹配成功、在评价范围内、两次考试均有有效成绩的学生。
2. 按科目分组；总分按“首选科目”分组（历史类、物理类）。
3. 每个科目使用任务中确定的计算基础值：原始分或高考赋分。
4. 缺考、剔除、缺失分数的记录不参与该科目计算。
5. 同一科目同一任务内不得混用两种分值口径。
6. 赋分缺失的科目整科回退原始分，并在任务与报告中标注。

## 2. 算法一：标准分增值法（Z 分差法）

### 2.1 适用场景

- 生源差异大，绝对分不可直接比较。
- 需要精细区分学生相对位置的变化。
- 需要弱化科目难度、试卷难度差异。

### 2.2 计算步骤

1. 对入口考试某科目，计算参与学生的平均分与标准差。
2. 计算每名学生的相对位置分：

   `位置分 =（本人分数 − 平均分）÷ 标准差`

3. 对评价考试同一科目重复步骤 1~2。
4. 计算位置变化：

   `位置变化 = 评价考试位置分 − 入口考试位置分`

5. 判定：

| 位置变化 | 判定 | 级数 |
|---|---|---|
| 绝对值 < 0.25 | 保持 | 0 |
| ≥ 0.25 | 进步 | 1 + floor((变化值 − 0.25) ÷ 0.5) |
| ≤ −0.25 | 退步 | −(1 + floor((绝对值 − 0.25) ÷ 0.5)) |

### 2.3 业务解释

- 0.25 个标准差以内视为正常波动。
- 超过 0.25 后，每多 0.5 个标准差加一级。
- 分数下降不一定退步，分数上升也不一定进步，关键看相对位置。

### 2.4 算例

| 学生 | 入口分 | 评价分 | 入口位置分 | 评价位置分 | 变化 | 判定 |
|---|---|---|---|---|---|---|
| A | 90 | 88 | +1.16 | +0.65 | −0.51 | 退步 1 级 |
| B | 80 | 92 | +0.39 | +0.97 | +0.58 | 进步 1 级 |
| C | 70 | 75 | −0.39 | −0.40 | −0.01 | 保持 |
| D | 60 | 65 | −1.16 | −1.21 | −0.05 | 保持 |

## 3. 算法二：等级差法

### 3.1 适用场景

- 面向教师、家长解释，强调“进了几档、掉了几档”。
- 不需要展示档内细微变化。

### 3.2 计算步骤

1. 入口考试按百分位划等级。
2. 评价考试用相同档数划等级。
3. 计算：

   `等级差 = 入口档位序号 − 评价档位序号`

   - 正数 → 进步
   - 负数 → 退步
   - 0 → 保持

4. 进退步级数 = 等级差的绝对值。

### 3.3 与标准分法的差异

| 维度 | 标准分法 | 等级差法 |
|---|---|---|
| 敏感度 | 高 | 低 |
| 解释成本 | 中 | 低 |
| 抗极端值 | 较好 | 好 |
| 推荐用途 | 主评价口径 | 辅助解读口径 |

## 4. 等级与权重

默认 7 档：

| 等级 | 百分位上限 | 权重 |
|---|---|---|
| G1 | 5% | 90 |
| G2 | 15% | 76.7 |
| G3 | 35% | 63.3 |
| G4 | 65% | 50 |
| G5 | 85% | 36.7 |
| G6 | 95% | 23.3 |
| G7 | 100% | 10 |

9 档预设：4%、10.5%、22.6%、40.1%、59.9%、77.4%、89.5%、96%、100%，权重 90、80、70、60、50、40、30、20、10。

自定义 2~15 档时，权重在 90 与 10 之间等距分配，末档为 10。

## 5. 汇总指标

| 指标 | 口径 |
|---|---|
| 学业实力 | Σ（本次各等级人数占比 × 等级权重） |
| 保持值 | Σ（保持学生入口等级权重 − 10）÷ 人数 |
| 进步值 | Σ（进步学生从入口等级向上跨级的权重）÷ 人数 |
| 退步值 | Σ（退步学生从入口等级向下跨级的 100 − 权重）÷ 人数 |
| 相对进步率 | （保持值 + 进步值 × 2）÷（（退步值 + 1）× 1.5） |
| 平均进退步级数 | Σ 级数 ÷ 人数 |
| 进步学生占比 | 进步人数 ÷ 参与人数 |

## 6. 排名规则

- 实力排名：按学业实力降序。
- 进步率排名：按相对进步率降序。
- 范围：同科目、同评价范围全体对象，不随页面筛选变化。
- 样本少于 8 人的对象不参与排名，标注“样本不足”。
- 并列时同名次，下一名次跳号。

## 7. 边界规则

| 场景 | 处理 |
|---|---|
| 全员同分 | 位置分统一为 0，全部保持 |
| 组内 1 人 | 不计算标准分，不排名，标注样本不足 |
| 缺考 | 不参与该科计算，不计入分母 |
| 极端值 | 保留，报告提示存在极端值 |
| 赋分缺失 | 整科回退原始分并标注 |
| 选科变化 | 变化前后科目不可直接比较，按异常规则排除或确认 |
| 跨年级 | 允许，报告显著提示 |
