# UI 设计规范 v3.1

> **2026-10-23 更新：** 系统内部已改为与首页一致的浅色、细边框、实心蓝按钮视觉。本文中的色彩、圆角、阴影与组件规格以 `UI一致性改造说明-v3.2.md` 为准；以下内容保留为历史规范，不再作为实现依据。

> 以 TaskFlow 设计语言为基础，做教育后台适配。所有颜色、圆角、阴影通过 CSS 变量管理。

## 1. 设计原则

- 清晰优先：信息层级明确，表格与筛选不抢视觉。
- 科技理性：蓝色主色、轻渐变、克制阴影。
- 一致性：按钮、chip、卡片、表格统一规格。
- 可读性：正文 14px，表格 13px，标签 12px。

## 2. 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--primary` | `#0A66FF` | 主按钮、选中态、链接 |
| `--primary-hover` | `#0056D4` | 悬浮 |
| `--primary-light` | `rgba(10,102,255,.08)` | 选中背景、标签底 |
| `--bg` | `#F5F7FB` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片、面板 |
| `--surface-2` | `#F9FAFB` | 次级面板、表头 |
| `--border` | `#E5E7EB` | 边框、分割线 |
| `--text` | `#111827` | 主文字 |
| `--text-2` | `#6B7280` | 次要文字 |
| `--text-3` | `#9CA3AF` | 占位、弱化 |
| `--success` | `#10B981` | 进步、成功 |
| `--warning` | `#F59E0B` | 待确认、注意 |
| `--danger` | `#EF4444` | 退步、阻断、删除 |
| `--info` | `#3B82F6` | 提示 |

## 3. 字体与字号

- 字体：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 页面标题 22px / 600
- 卡片标题 15px / 600
- 正文 14px / 400
- 表格 13px / 400
- 辅助 12px / 400
- 数字强调 26px / 600

## 4. 布局

- 顶栏 64px，左侧栏 232px，内容区自适应。
- 页面内边距 24px，卡片间距 16px。
- 卡片圆角 14px，边框 1px，阴影 `0 1px 2px rgba(16,24,40,.04)`。
- 表格行高 44px，表头 40px。
- 桌面优先，最小适配宽度 1280px。

## 5. 组件

### 按钮

- 高度 36px（小号 30px），圆角 8px，字号 13px。
- 主按钮：主色底、白字；次按钮：白底、边框；幽灵按钮：透明底。
- 危险按钮：红色描边，二次确认。

### Chip

- 高度 28px，圆角 999px，边框 1px。
- 选中：主色底、白字。
- 用于科目、班级、教师、状态筛选。

### 徽章

- 高度 22px，圆角 999px，字号 12px。
- 类型：成功、警告、危险、信息、中性。

### 表格

- 表头浅灰底，文字 12px，字重 600。
- 行悬浮浅蓝底；斑马纹可选。
- 数字右对齐；长文本省略并悬浮提示。
- 表头可 sticky；首列可固定。

### 卡片

- 标题区：标题 + 可选说明 + 右侧操作。
- 内容区：留白 16~20px。

### 进度

- 轨道 6px，圆角 999px，填充主色渐变。
- 阶段进度需同时显示文字百分比与阶段名。

### 弹窗 / 抽屉

- 弹窗最大宽度 720px，圆角 16px。
- 抽屉从右侧滑入，宽度 480px，用于明细查看。

## 6. 反馈

- Toast：右上角，3 秒消失。
- 成功：绿色左边框；失败：红色；提示：蓝色。
- 危险操作必须二次确认。

## 7. 图表

- 柱状图：主色渐变，负值用红色。
- 分布图：进步绿、保持灰、退步红。
- 坐标轴弱化，数据标签直接显示。
- 无外部图表库，使用原生 SVG。

## 8. 可访问性

- 所有交互元素可 Tab 聚焦，有清晰 `:focus-visible`。
- 颜色不是唯一信息载体，状态同时有文字。
- 尊重 `prefers-reduced-motion`。
