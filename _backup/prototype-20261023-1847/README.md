# 增值评价系统 · 原型（高中园数据与评价任务版）

> 本期包含：深圳外国语学校高中园四校的**基础数据**、**两场成绩数据**、**评价任务（四类结果）**与**六类角色报告**。
> 不含看板、矩阵与多次考试趋势。

## 1. 打开

直接双击 `index.html` 打开首页兼登录页，输入账号密码后进入 `app.html`；已登录时也可直接双击 `app.html`。

或启动静态服务：

```bash
cd prototype
python -m http.server 8099
```

访问 `http://localhost:8099` 为首页（登录页）；登录后进入系统 `app.html`。

## 2. 本期范围

### 已导入

- 4 所学校：博雅高中、弘知高中、理工高中、致远高中；
- 每校 1 个实际年级：2027 届高三（2024 入学）；
- 每校 2 个版本：V1 高二期末快照、V2 高三当前；
- 当前 59 个班、2,812 名学生；
- 202 名任课教师；
- 2 场考试：2024 级高二期末（入口）、2024 级高三（评价）；
- 约 3.28 万条成绩记录，含原始分、赋分、缺考标记；
- 8 条按学校拆分的成绩导入记录。

### 已接入

- 评价任务列表；预置 1 个已完成四校联考任务（可计算样本 2,496 人）；
- 新建任务 → 配置 → 匹配确认 → 算法参数 → 计算 → 四类结果；
- 学生、班级、教师、学校四张结果表，支持科目切换、筛选、分页、CSV 导出；
- 任务列表“查看结果”旁新增“查看报告”：区域/联考、校长、年级主任、班主任、科任教师、学生六页，含结论、指标、内联 SVG 图表、名单与建议；
- 报告只读结果版本，支持对象切换（学校/班级/科目/教师/学生）与浏览器打印；学校管理员锁定本校；
- 匹配异常基于真实数据生成：仅入口 99、仅评价 18、成绩不完整 297、外语科目变更 1、班级变更 2,322、教师任课缺失 0（理工6/8班政治已补王雅薇）。

### 本期不做

- 教师看板、学生矩阵、多次考试趋势；
- 独立 PDF 排版导出（浏览器打印可用）；
- 成绩上传/重新导入向导（入口已隐藏，数据已预置）；
- 基础数据导入向导（入口已隐藏，数据已预置）。

## 5. 数据说明

- 数据由 `tools/build_dataset.py` 从 `高中园/*.xls` 生成，输出 `assets/js/mock/dataset.js`。
- 学校、年级、班级、学生、教师、任课、版本、考试、成绩均为真实数据。
- 学生姓名、学号、教师姓名使用真实值；教师手机号/账号不写入原型，工号按学校重新生成。
- 外语按源数据拆为**英语、日语、俄语**三个独立科目；每个学生只考其中一个，“外语”只作分组标签。
- 逐条成绩优先赋分，赋分缺失时回退原始分；物理/历史当前源表无赋分，因此使用原始分。
- 数据仅限内部演示，含真实个人信息，请勿公开传播。

## 6. 演示路线

1. 首页输入账号密码登录 → 基础数据 → 选择博雅高中 → 2027 届高三 → 查看班级/版本；
2. 打开高三 14 班，查看日语/俄语教师与学生名单；
3. 基础数据 → 教师 Tab，查看 63 名教师及任教学科；
4. 考试管理 → 打开高二期末或高三考试 → 查看学生单行成绩单、分页、姓名/学号检索与导入记录；
5. 评价任务 → 打开预置任务查看四类结果；或新建任务走“配置 → 匹配 → 算法 → 计算”；
6. 结果页切换学生/班级/教师/学校 Tab，切换科目，导出 CSV；
7. 结果页或任务列表点“查看报告”，依次查看区域/校长/年级主任/班主任/科任教师/学生六页，切换学校/班级/科目/教师/学生；
8. 结果页 → “计算过程”，逐步查看数据口径、联考统计、学生标准化、等级判定、四层汇总；在“学生标准化”列表点击学生姓名或“查看计算”，查看该生从原始输入、赋分采用、z/等级/判定到总分和汇总贡献的完整链路；在“四层汇总 → 班级”点击班级名称或“查看计算”，查看班级成员逐人贡献和汇总公式代入；在“数据与口径”下方用 Tab 查看正常样本、学生异常、成绩异常清单；
9. 系统管理员 → “参数配置”，维护默认 9 档、阈值、步长、小样本和默认算法；
10. 帮助 → “算法说明”，查看独立完整文档（含 9 档规则、学生/班级完整示例）。
