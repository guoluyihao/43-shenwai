# 增值算法说明 v3.0（多校联考版）

> 业务口径说明，不涉及代码实现。单校评价是多校联考的特例。

## 1. 统计总体

- 每个科目以**联考全体参与学生**为总体。
- 总分按“首选科目”分组：物理类、历史类，各自在联考全体内计算。
- 学校、班级、教师的结果都由学生结果汇总，不单独重新排名。

## 2. 学生层计算

### 2.1 标准分增值法

1. 某科目联考全体均值 `mean`、标准差 `std`。
2. 标准分 `z = (score - mean) / std`。
3. 入口、评价各算一次。
4. 位置变化 `Δz = z评价 - z入口`。
5. 判定：

| Δz | 判定 | 级数 |
|---|---|---|
| 绝对值 < 0.25 | 保持 | 0 |
| ≥ 0.25 | 进步 | 1 + floor((Δz - 0.25) / 0.5) |
| ≤ -0.25 | 退步 | -(1 + floor((|Δz| - 0.25) / 0.5)) |

### 2.2 等级差法

1. 入口、评价分别按联考全体百分位划等级。
2. 等级差 = 入口档位序号 − 评价档位序号。
3. 正数为进步，负数为退步，0 为保持；级数 = 绝对值。

### 2.3 等级与权重

默认 7 档：

| 等级 | 百分位上限 | 权重 |
|---|---|---|
| G1 | 5% | 90 |
| G2 | 15% | 76.7 |
| G3 | 35% | 63.3 |
| G4 | 65% | 50 |
| G5 | 85% | 36.7 |
| G6 | 95% | 23.3 |
| G7 | 100% | 10 |

9 档预设：4%、10.5%、22.6%、40.1%、59.9%、77.4%、89.5%、96%、100%，权重 90 到 10。

### 2.4 总分

- 总分 = 六科按本次口径求和。
- 任一科缺失或非正常，总分标记“不完整”，不参与总分排名。
- 总分在“首选科目”组内标准化与划等级。

## 3. 四层汇总

### 3.1 学生

- 输出入口值、评价值、等级变化、进退步、级数。
- 学生排名与等级按联考全体。

### 3.2 班级

- 分组：学校 + 班级 + 科目/总分。
- 指标：学业实力、保持值、进步值、退步值、相对进步率、平均进退步、进步/退步占比。
- 排名：校内同科目。

### 3.3 教师

- 分组：学校 + 教师 + 科目/总分。
- 指标同班级。
- 排名：校内同科目。
- 主责教师归属；多教师任课时在结果中注明。

### 3.4 学校

- 分组：学校 + 科目/总分。
- **指标与班级完全一致**。
- 排名：联考全体同科目。

## 4. 指标公式

| 指标 | 公式 |
|---|---|
| 学业实力 | Σ（本次各等级人数占比 × 权重） |
| 保持值 | Σ（保持学生入口等级权重 − 10）÷ 人数 |
| 进步值 | Σ（进步学生从入口等级向上跨级的权重）÷ 人数 |
| 退步值 | Σ（退步学生从入口等级向下跨级的 100 − 权重）÷ 人数 |
| 相对进步率 | （保持值 + 进步值 × 2）÷（（退步值 + 1）× 1.5） |
| 平均进退步 | Σ 级数 ÷ 人数 |
| 进步占比 | 进步人数 ÷ 人数 |

## 5. 排名范围

| 对象 | 范围 | 说明 |
|---|---|---|
| 学生 | 联考全体 | 跨校可比 |
| 班级 | 校内 | 校内诊断 |
| 教师 | 校内 | 校内评价 |
| 学校 | 联考全体 | 校际比较 |

## 6. 边界规则

| 场景 | 处理 |
|---|---|
| 全员同分 | 标准分 0，全部保持 |
| 组内 1 人 | 样本不足，不排名 |
| 缺考 | 不参与该科计算 |
| 赋分缺失 | 整科回退原始分并标注 |
| 学校单边参与 | 只算共同学校，单边进异常 |
| 班级/教师少于 8 人 | 不排名，标注 |
| 选科变化 | 涉及科目不可比，按异常处理 |
| 两场考试版本不一致 | 默认评价考试版本，入口差异进异常 |

## 7. 与单校版的关系

- 单校：联考全体 = 本校全体，结果与旧版一致。
- 多校：所有学校放在同一总体内标准化，学校结果才有比较意义。
- 不支持“每校各自标准化后直接比较学校”，该口径会使学校结果失真。
