## 1. 术语

| 术语 | 含义 |
|---|---|
| 学校 | 参与评价的独立单位 |
| 学段 | 高中 / 初中 |
| 年级层次 | 高一/高二/高三，初一/初二/初三 |
| 实际年级 | 学校内的一届学生，如“2026 届高三”，由学校 + 学段 + 年级层次确定 |
| 年级版本 | 某个学校某个实际年级在某一时点的基础数据快照，如“分班后 v1”“高三调整后 v2” |
| 班级 | 年级下的行政班 |
| 班主任 | 班级的第一责任人，一名教师 |
| 科任老师 | 在某个班级任教某个科目的教师 |
| 教师 | 学校级教师库中的成员，单列维护 |
| 联考 | 一场包含多所学校的统一考试 |
| 考试 | 一次具体的考试活动，包含名称、时间、参与学校、年级、版本、科目 |
| 成绩单 | 只包含学生成绩的 Excel/CSV 文件 |
| 原始分 | 卷面分 |
| 高考赋分 | 原始分按新高考规则转换后的分数，由外部提供 |
| 计算基础值 | 本次评价使用的分值口径：原始分或高考赋分 |
| 评价任务 | 一次完整的增值评价，包含入口考试、评价考试、按校版本、算法与结果 |
| 联考全体 | 本次评价所有参与学校、所有匹配成功的学生 |
| 学生结果 | 学生维度的增值结果 |
| 班级结果 | 班级维度的汇总结果 |
| 教师结果 | 教师维度的汇总结果 |
| 学校结果 | 学校维度的汇总结果，指标与班级结果一致 |

> 本文件中“赋分”一律指**高考赋分**，不是系统内部生成的分数。

## 2. 产品定位与本期范围

### 2.1 定位

面向多所学校联考场景的成绩增值评价工具：

1. 维护学校、年级、班级、学生、教师、任课与版本。
2. 以“联考”为单位录入成绩，只导成绩单。
3. 以评价任务组合入口考试与评价考试，按学校选择版本。
4. 按联考全体统一计算增值，输出学生、班级、教师、学校四层结果。

### 2.2 本期目标

- 基础数据可维护、可版本化、可追溯。
- 联考成绩可多次导入、覆盖旧数据、保留导入记录。
- 评价任务可跨校组合，按校选版本。
- 四层结果可查看、可筛选、可导出。
- 按区域/联考、校长、年级主任、班主任、科任教师、学生六种视角查看分析报告。

### 2.3 本期不做

- 工作台。
- 独立版本管理菜单。
- 独立导入记录菜单。
- 独立结果菜单。
- 教师看板、学生矩阵。
- 多次考试趋势、AI 报告、自定义算法。
- 历史数据迁移。

## 3. 角色与权限

| 角色 | 定位 | 数据范围 |
|---|---|---|
| 系统管理员 | 平台运营/实施，负责全部维护与评价 | 全部学校 |
| 学校管理员 | 学校侧查看人员，只读 | 仅本校 |

| 功能 | 系统管理员 | 学校管理员 |
|---|---|---|
| 学校建档、启停 | 可操作 | 查看本校 |
| 基础数据维护（年级/班级/学生/教师/任课/科目） | 可操作 | 查看本校 |
| 维护年级版本（生成/覆盖/删除） | 可操作 | 不可 |
| 新增/删除考试 | 可操作 | 不可 |
| 上传成绩单、确认导入 | 可操作 | 不可 |
| 查看考试成绩与导入记录 | 可操作 | 查看本校 |
| 新建/配置评价任务 | 可操作 | 不可 |
| 确认匹配、选择算法、计算 | 可操作 | 不可 |
| 查看四类结果、导出 | 全部学校 | 本校 |
| 修改本人密码 | 可操作 | 可操作 |

> “只读”包括查看、筛选、排序、导出；不包含新增、修改、删除、保存版本、导入、确认、计算。

## 4. 信息架构与菜单

```
登录
├── 学校管理（系统管理员）
├── 基础数据
│   ├── 年级 → 班级 → 学生 / 班主任 / 科任老师
│   ├── 教师（单列）
│   ├── 科目
│   └── 年级版本（在年级详情内）
├── 考试管理
│   ├── 考试列表
│   ├── 新增考试
│   ├── 考试详情（成绩 + 导入记录）
│   ├── 导入向导
│   └── 删除考试
└── 评价任务
    ├── 任务列表
    ├── 新建/配置
    ├── 匹配与确认
    ├── 算法与计算
    └── 结果（学生 / 班级 / 教师 / 学校）
```

- 完整版登录后默认进入**评价任务**；本期原型登录后进入**基础数据**，评价任务已接入。
- 系统管理员基础数据先进入**学校列表**，再进入**年级列表**，不通过顶部切换学校。
- 新增考试必须显式“选择学校”，确认后才展示实际年级、版本与科目。
- 结果只能从评价任务详情进入。
- 不再有工作台、独立版本管理、独立导入记录、独立结果菜单。

## 5. 基础数据

### 5.1 学校

| 字段 | 规则 |
|---|---|
| 学校名称 | 必填，全局唯一 |
| 学校编码 | 必填，全局唯一 |
| 管理员账号 | 必填，绑定学校管理员 |
| 状态 | 启用 / 停用 |
| 城市 | 可空 |

### 5.2 年级

| 字段 | 规则 |
|---|---|
| 实际年级名称 | 如“2026 届高三”，同校唯一 |
| 学段 | 高中 / 初中 |
| 年级层次 | 高中：高一/高二/高三；初中：初一/初二/初三 |
| 入学年份 | 必填 |
| 状态 | 在读 / 已毕业 |

- 实际年级 = 学校 + 学段 + 年级层次 + 入学年份。
- 同校同学段同层次只保留一个在读实际年级。
- 系统管理员进入基础数据时，先显示学校列表，再显示该学校的年级列表。
- 系统管理员可在年级列表手工“新增年级”；新增后为当前编辑稿，需导入学生名单并在更新时生成版本。
- 考试配置时先选学段，再选年级层次，系统自动带出学校对应的实际年级。

### 5.3 年级版本（更新时生成 / 覆盖，可删除）

| 字段 | 规则 |
|---|---|
| 版本号 | 自动生成，如 V1、V2 |
| 版本名称 | 必填，如“分班后”“高三调整后” |
| 状态 | 已保存 / 已停用 |
| 来源 | 导入生成 / 手动保存 / 覆盖 |
| 保存时间 / 保存人 | 系统记录 |
| 变更说明 | 必填 |
| 被引用 | 被考试、评价任务引用的次数 |

规则：

1. 版本属于“学校 + 实际年级”，不是独立模块。
2. 基础数据导入在“确认更新”时决定版本处理方式，**默认存为新版本**。
3. 勾选“存为新版本”：应用差异后，把更新后的学生、班级、教师、任课关系保存为新版本；旧当前版本转为“已停用”，旧版本保留。
4. 取消勾选“存为新版本”：必须二次确认“将覆盖当前版本 Vx”，确认后更新后的数据覆盖当前版本，不新增版本，原内容不可恢复；若当前版本已被考试或评价任务引用，不允许覆盖，只能存为新版本。
5. 当前编辑稿不是版本；新增年级在保存版本前不能被考试引用。
6. 已保存版本只读；“覆盖当前版本”是唯一的显式覆盖操作。
7. 考试和评价任务只引用“已保存版本”，未保存修改不可用于正式评价。
8. 同一学校同一实际年级同一时间只允许一个“当前版本”。
9. 版本可删除：仅系统管理员可操作；当前版本不可删；被考试或评价任务引用的版本不可删；其余历史版本可删。删除不影响当前数据，删除后不可恢复。
10. 年级详情保留“保存版本”按钮，作为手动备份当前数据的入口。

### 5.4 班级

| 字段 | 规则 |
|---|---|
| 班级名称 | 如“高三(1)班”，同一学校同一实际年级内唯一 |
| 所属实际年级 | 必填 |
| 班主任 | 必填，一名教师 |
| 学生数 | 统计值 |

- 班级详情展示：学生名单、班主任、各科科任老师。

### 5.5 学生

| 字段 | 规则 |
|---|---|
| 学籍号 | 必填，全局唯一，匹配主键 |
| 姓名 | 必填 |
| 学校 / 实际年级 / 班级 | 必填 |
| 选科组合 | 高中必填，3+1+2；初中可空 |
| 外语语种 | 高中必填，英语 / 日语 / 俄语三选一 |
| 状态 | 在读 / 转出 / 转学 / 休学 / 毕业 |

### 5.6 教师

| 字段 | 规则 |
|---|---|
| 工号 | 必填，全局唯一 |
| 姓名 | 必填 |
| 学校 | 必填 |
| 任教学科 | 必填，必须属于该学段科目 |
| 是否班主任 | 由班级关系决定 |
| 状态 | 在职 / 离职 |

- 教师在学校级单列，不在班级里重复维护。
- 班级通过“班主任”和“科任关系”引用教师。

### 5.7 任课与班主任

| 关系 | 规则 |
|---|---|
| 班主任 | 班级属性，一名教师 |
| 科任老师 | 教师 × 班级 × 科目；同一班级同一科目可多名，需标记主责 |
| 教师评价归属 | 默认按主责教师；无主责时按全部任课教师并提示 |

### 5.8 科目（按学段写死）

基础数据中**不再提供科目管理**，科目由学段自动决定。

| 学段 | 固定科目 |
|---|---|
| 高中 | 语文、数学、英语、日语、俄语、物理、化学、生物、历史、政治、地理 |
| 初中 | 语文、数学、英语、物理、化学、生物、历史、地理、道德与法治 |

规则：

1. 科目名称、顺序、类型、计分方式均按学段内置，不允许学校自行增删。
2. 外语拆为英语、日语、俄语三个独立科目；每个学生只考其中一个，“外语”仅作分组标签，不作为成绩科目。
3. 考试只能选择该学段科目列表中的科目；同一场考试可同时包含英语、日语、俄语。
4. 评价任务、结果表、导出均使用该学段固定顺序；结果按实际语种分别呈现。
5. 高中按 3+1+2 口径：语文/数学/外语（英语、日语、俄语三选一）为必考，物理/历史为首选，化学/生物/政治/地理为再选。
6. 初中不区分选科；本期初中只保留英语，所有科目按原始分计入。

### 5.9 基础数据导入

基础数据不再提供独立的新增、编辑、删除入口，所有变更通过导入文档完成。

支持文档：

| 文档 | 可更新内容 |
|---|---|
| 学生名单 | 学生、班级、选科、状态 |
| 教师名单 | 教师、学科、状态 |
| 任课安排 | 班主任、科任关系、主责标记 |

流程：

1. 选择目标学校与实际年级。
2. 上传文档（Excel / CSV，可多文件）。
3. AI 解析并匹配到当前编辑稿。
4. 生成差异清单（新增、缺失、班级变更、选科变更、教师变更等）。
5. 人工确认差异。
6. 点击“更新当前编辑稿”，弹出更新确认：
   - “存为新版本”默认勾选，可填写版本名称与变更说明；
   - 取消勾选时，二次确认“将覆盖当前版本 Vx”。
7. 确认后应用差异。
   - 勾选：生成包含更新后数据的新版本，旧当前版本转“已停用”。
   - 取消勾选：覆盖当前版本，不新增版本。
8. 更新完成后不再要求“更新后再保存版本”。

规则：

- 未确认的解析结果不写入编辑稿。
- 基础数据导入不提供“手工新增/删除”作为替代入口；新增年级除外。
- 缺失学生标记为“转出”，保留历史，不物理删除。
- 学生名单中的班级如果不存在，自动创建班级。
- 教师名单、任课安排必须真正更新教师库与任课关系，不只是提示。
- 当前无已保存版本时，必须存为新版本，不能走覆盖。
- 当前版本已被考试/评价任务引用时，不能覆盖，只能存为新版本。
- 版本删除规则见 5.3：当前版本、被引用版本不可删除。
- 学校管理（新增学校、启停、重置密码）仍由系统管理员手工维护。
- 导入差异与考试成绩导入共用同一套确认机制。

## 6. 考试管理

### 6.1 考试（联考）

| 字段 | 规则 |
|---|---|
| 考试名称 | 必填 |
| 考试时间 | 必填 |
| 学段 | 高中 / 初中 |
| 年级层次 | 高一/高二/高三 或 初一/初二/初三 |
| 参与学校 | 只显示该学段、该年级层次下存在实际年级的学校，可多选 |
| 每校实际年级 | 系统自动带出，不可手工改 |
| 每校基础数据版本 | 系统自动带出该实际年级的**最新已保存版本** |
| 参与科目 | 从该学段固定科目中多选 |
| 状态 | 草稿 / 已发布 |

规则：

- 一场考试只能包含同一学段、同一年级层次的学校。
- 选择学段与年级层次后，系统自动匹配每所学校的实际年级（如“2026 届高三”）。
- 自动使用该实际年级的最新已保存版本；没有已保存版本的学校不可选。
- 考试保存时固化 versionId，后续再保存新版本不影响已创建的考试。
- 考试发布后才可被评价任务引用。
- 成绩导入前必须先完成考试配置。

### 6.2 新增考试

流程：

1. 填写考试名称、考试时间。
2. 选择学段（高中/初中）。
3. 选择年级层次（高三/高二/高一，或初三/初二/初一）。
4. 点击“选择学校”，在弹窗中列出该学段、该年级层次下存在实际年级的学校。
5. 勾选参与学校（可多选），确认后才展示学校配置。
6. 系统自动带出每校的实际年级与最新已保存版本。
7. 从该学段固定科目中选择参与科目。
8. 保存后进入考试详情，上传成绩单。

### 6.3 成绩单导入

- 只上传**成绩单**，不需要学生名册、教师名单、任课表。
- 文件类型：Excel（.xlsx/.xls）与 CSV。
- 流程：上传 → AI 解析 → 与考试/学校/年级/版本匹配 → 差异确认 → 入库。
- 一个导入任务可包含多所学校的成绩文件。
- **同一考试同一时间只允许一个导入任务**。
- **按学校覆盖**：本次导入涉及哪所学校，就替换该校旧成绩；未涉及学校保持不变。
- **已完成评价任务的结果不变**：重新导入成绩不自动改写历史结果；新建或重算任务时使用新成绩。
- 入库后只保存成绩，**不做平均分、排名、统计、分析**。
- 导入记录保存在考试详情内，不单独设菜单。

### 6.4 导入差异

| 级别 | 示例 | 处理 |
|---|---|---|
| 阻断 | 无法识别学生、重复记录、分数越界、文件损坏 | 必须逐条处理，清零后才能入库 |
| 待确认 | 新增学生、缺失学生、班级变更、选科变更、赋分缺失 | 逐条或批量确认 |
| 提示 | 低置信度字段、科目别名、格式不统一 | 可批量接受 |

### 6.5 考试详情

展示：

- 考试基本信息：名称、时间、参与学校、年级、版本、科目。
- 成绩单：一个学生一行，横向展示学号、姓名、学校、班级、各科成绩与总分；再选科目同时展示原始分和赋分两列；支持按姓名/学号检索、分页、每页条数切换。
- 未选科目显示“—”，已选但缺考显示“缺考”；总分按原始分、赋分分别展示。
- 导入记录：批次、文件、学校、时间、成功/跳过/失败、差异处理。
- 操作：上传/重新导入、删除考试。

### 6.6 删除考试

- 支持删除考试。
- 已产生评价任务的考试禁止删除，提示先删除关联评价任务。

### 6.7 成绩字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 学校 | 是 | 联考中的参与学校 |
| 学生 | 是 | 必须属于该校所选年级 |
| 科目 | 是 | 必须在考试科目范围内；外语为英语/日语/俄语之一 |
| 原始分 | 是 | 0 ~ 满分 |
| 高考赋分 | 否 | 外部提供；无则为空 |
| 缺考标记 | 是 | 正常 / 缺考 / 免考 |

### 6.8 赋分规则

1. 高考赋分由外部提供，系统不计算。
2. 有就存，没有就留空。
3. 评价时逐条成绩优先使用赋分，赋分缺失时回退原始分。
4. 赋分缺失的逐条成绩回退原始分，并在结果中标注。

## 7. 评价任务

### 7.1 新建与配置

| 配置项 | 规则 |
|---|---|
| 任务名称 | 必填 |
| 入口考试 | 必填，已发布 |
| 评价考试 | 必填，已发布 |
| 参与学校 | 默认取两次考试共同参与的学校 |
| 每校版本 | 默认取评价考试配置的版本，可覆盖 |
| 评价范围 | 学校 / 年级 / 班级 / 科目 |
| 计算基础值 | 任务默认 + 科目覆盖 |
| 算法 | 标准分增值法 / 等级差法 |
| 参数 | 等级档数、阈值、步长、小样本阈值 |

### 7.2 按学校选版本

- 联考包含多所学校时，逐校选择对应实际年级的**已保存版本**；已停用的历史版本仍可选，界面需标注“历史”。
- 默认使用评价考试中该校固化的版本。
- 若该实际年级已有更新的已保存版本，可手动改选；入口考试版本不一致时进入异常确认。
- 版本决定班级、学生、班主任、科任老师的归属。
- 未保存的编辑稿不可用于评价任务。

### 7.3 计算基础值

- 任务级默认：原始分 / 高考赋分。
- 科目级覆盖：可逐科指定；科目来自该学段固定科目。
- 默认按科目计分方式带出。
- 同一科目同一任务只能一种口径。
- 赋分缺失时逐条回退原始分并提示。
- 结果表必须标注本次口径。

### 7.4 匹配

- 学生：学籍号优先，身份证号兜底，姓名+班级辅助。
- 学校：按考试参与学校匹配。
- 班级、科目、教师：按版本与任课关系匹配。
- 两场考试参与学校不一致时，只计算共同参与学校；单边学校进入异常清单。
- 阻断项清零后才能进入算法。

### 7.5 任务状态

草稿 → 待匹配 → 匹配待确认 → 待计算 → 计算中 → 已完成 / 失败。

- 等级档数、保持阈值、步长、小样本阈值必须参与实际计算。
- 重算生成新的结果版本（R1、R2……），旧结果保留，可追溯。

## 8. 多校联考算法

### 8.1 统计总体

- 每个科目以**联考全体参与学生**为统计总体。
- 总分按“首选科目”分组（物理类 / 历史类），同样在联考全体内计算。
- 单校评价是多校的特例。

### 8.2 学生结果

1. 计算联考全体某科目均值、标准差。
2. 标准分 =（本人分数 − 均值）÷ 标准差。
3. 按标准正态 Z 区间划分等级，Z 限幅 [-3.1, 3.1]。
4. 比较入口与评价考试标准分变化，判定进退步。
5. 等级差法直接比较入口等级与评价等级。

### 8.3 四层汇总

| 层级 | 分组 | 指标 |
|---|---|---|
| 学生 | 学生 × 科目/总分 | 标准分、等级、进退步 |
| 班级 | 学校 + 班级 + 科目/总分 | 与班级指标一致 |
| 教师 | 学校 + 教师 + 科目/总分 | 与班级指标一致 |
| 学校 | 学校 + 科目/总分 | **与班级指标完全一致** |

学校结果指标：

- 学业实力
- 保持值
- 进步值
- 退步值
- 相对进步率
- 平均进退步级数
- 进步学生占比 / 退步学生占比
- 实力排名
- 进步率排名

### 8.4 排名范围

| 对象 | 范围 |
|---|---|
| 学生 | 联考全体同科目 |
| 班级 | 校内同科目 |
| 教师 | 校内同科目 |
| 学校 | 联考全体同科目 |

### 8.5 指标公式

| 指标 | 口径 |
|---|---|
| 学业实力 | Σ（本次各等级人数占比 × 等级权重） |
| 保持值 | Σ（保持学生入口等级权重 − 10）÷ 人数 |
| 进步值 | Σ（进步学生从入口等级向上跨级的权重）÷ 人数 |
| 退步值 | Σ（退步学生从入口等级向下跨级的 100 − 权重）÷ 人数 |
| 相对进步率 | （保持值 + 进步值 × 2）÷（（退步值 + 1）× 1.5） |
| 平均进退步 | Σ 级数 ÷ 人数 |
| 进步占比 | 进步人数 ÷ 人数 |

### 8.6 边界

| 场景 | 处理 |
|---|---|
| 全员同分 | 标准分为 0，全部保持 |
| 组内 1 人 | 样本不足，不排名 |
| 缺考 | 由任务参数决定：整生剔除，或仅剔除该科 |
| 赋分缺失 | 逐条回退原始分并标注 |
| 学校单边参与 | 只算共同学校，单边进异常 |
| 班级/教师样本不足 | 不参与排名，标注 |
| 选科变化 | 涉及科目不可比，按异常处理 |

## 9. 结果呈现

### 9.1 入口

- 只能从评价任务详情进入。
- 四个 Tab：学生结果、班级结果、教师结果、学校结果。
- 第一版只做表格、筛选、分页、导出。
- 结果页提供“计算过程”辅助页，按数据与口径、联考统计、学生标准化、等级与判定、四层汇总展示实际输入数据与中间结果；学生标准化列表可点击学生，查看原始输入、采用方式、标准分、等级、判定、总分和汇总贡献的完整链路；四层汇总的班级行可点击，查看班级成员逐人贡献和汇总公式代入；算法原理、9 档说明和学生/班级完整示例放在独立“算法说明”文档/页面，不放在计算过程内。
- “数据与口径”中统计在上，下方以 Tab 常驻展示正常样本、学生异常、成绩异常三张清单；学生异常按仅入口/仅评价/两场未满六科/外语语种变更过滤，支持姓名/学号检索和分页。

### 9.2 学生结果

字段：

- 学号、姓名、学校、班级
- 科目 / 总分
- 入口值、评价值
- 联考排名
- 入口等级、评价等级、等级变化
- 进退步、进退步级数

默认一行一个学生（总分），可切换科目查看单科。

### 9.3 班级结果

字段：

- 学校、班级、人数
- 学业实力、保持值、进步值、退步值、相对进步率
- 平均进退步、进步占比、退步占比
- 实力排名（校内）、进步率排名（校内）

### 9.4 教师结果

字段：

- 学校、教师、科目、任教班级、人数
- 学业实力、相对进步率、平均进退步、进步占比
- 实力排名（校内）、进步率排名（校内）

### 9.5 学校结果

字段与班级结果一致：

- 学校、人数
- 学业实力、保持值、进步值、退步值、相对进步率
- 平均进退步、进步占比、退步占比
- 实力排名（联考）、进步率排名（联考）

### 9.6 算法说明

- 提供独立公开文档 `algorithm.html`（无需登录）和 Markdown 文档，不放进计算过程；
- 公开版必须脱敏：只使用虚构学生/班级数据，不出现真实姓名、学号、学校、班级、教师；
- 内容包含口径、数据准备、统计量、标准分、权重专章、9 档等级、判定、四层汇总、边界规则、虚构学生/班级完整示例、结果解读、常见问题；
- 9 档为默认；档位支持自定义配置，不同档位配置的权重不得混用。

### 9.7 参数配置

- 仅系统管理员可访问；
- 维护新建任务的默认参数：等级档数、保持阈值、每级步长、小样本阈值、部分缺考处理、默认算法；
- 参数只影响新建任务，已完成任务保留自己的参数和结果快照；
- 9 档 Z 区间与权重固定只读，避免配置出不可解释的口径；档位支持自定义配置，变更后生成新的结果版本。

### 9.8 角色化报告

- 任务列表与结果页提供“查看报告”入口；报告只能从已完成任务进入。
- 报告按六个视角组织：区域/联考、校长、年级主任、班主任、科任教师、学生；每个视角一页，页内可切换视角。
- 每页包含：报告头（读者、范围、口径、结果版本）、一页结论、关键指标、1—2 张图、名单/明细、建议、脚注。
- 校长报告固定六段：① 这轮怎么样（状态 + 一句话 + 三个数）；② 问题在哪（入口位置 / 物理历史方向 / 班级 / 学科四行）；③ 最集中的班和科（班级 × 学科）；④ 涉及多少学生（四个固定标签）；⑤ 先找谁、做什么（教学 / 班级管理 / 两周后）；⑥ 数据依据。
- 每个槽位固定状态：重点关注 / 关注 / 正常 / 较好；无显著问题时保留槽位并显示对应状态，不因数据好坏改变页面结构。
- 正文使用校长语言：入口前约 23%、掉 2 档、比其他三校入口相近学生高 X 个百分点、需要重点关注的学生；系统术语（G1–G3、相对进步率、退步值、超额、pp）只放在数据依据和脚注。
- 正文后附“07 数据全貌”：A1 四校总表、A2 四校×学科、B1 入口位置、B2 物理/历史、B3 班级全表、C1 学科全表、C2 全部学生班级×学科、C3 需重点关注学生班级×学科、D1 班级×标签、D2 完整学生名单、E 数据质量；正文每段标注“核对位置”，附录高亮正文提到的班级/学科。
- 全科目固定顺序：语文、数学、英语、物理、历史、化学、生物、政治、地理、日语、俄语；学生个人六科按“语文、数学、外语（实际语种）、首选（实际科目）、化学、生物、政治/地理”排列。
- 结构扫描与热点矩阵固定；同段基准优先取其他学校，单校任务回退全校。入口段分析必须提示均值回归，不得把“高入口学生退步更多”直接归因为教学。
- 区域/联考、年级主任、班主任、科任教师、学生均按同一“六段 + 07 数据全貌 + 核对位置”框架改造；数据范围与隐私各自裁剪：区域只到学校/学科汇总、不含学生姓名；班主任仅本班；科任仅本科目/所教班；学生仅本人。
- 班主任页可切换班级，科任页可切换科目/教师，学生页可切换班级/学生并支持姓名/学号检索；选项按账号权限生成，切换后整页与附录重算、回到页首，PDF 导出当前对象。
- 报告为静态文档：所有章节展开，不做筛选/折叠；右侧固定目录导航，滚动高亮当前章节；支持浏览器打印导出 PDF（A4 纵向），附录随主报告一起导出；另提供全量数据 CSV 导出。
- 报告只读结果，不重新计算；对比、差值、百分比为报告层派生，必须注明口径，不得改写原指标。
- 班级/教师排名为校内排名，学校排名为联考排名；人数少于小样本阈值的班级/教师只展示指标、不排名。
- 教师报告不公开个人排名，只给本人/教研组长查看；学生报告只展示本人数据。
- 报告绑定结果版本，重算后重新生成；报告不做跨版本拼数，不在报告里手工改数。

## 10. 业务规则

| 编号 | 规则 |
|---|---|
| R01 | 基础数据按“学校→实际年级→班级”组织，版本跟实际年级走 |

| R06 | 同一考试同一时间只允许一个导入任务 |
| R07 | 新导入按学校覆盖旧成绩，未涉及学校不变 |
| R08 | 入库后不做统计与分析 |
| R09 | 已产生评价任务的考试不可删除 |
| R10 | 评价任务按学校选择已保存版本，默认取评价考试固化的版本 |
| R11 | 多校联考按联考全体统一标准化 |
| R12 | 学生按联考排名，班级/教师按校内排名，学校按联考排名 |
| R13 | 学校结果指标与班级结果完全一致 |
| R14 | 第一版输出四类结果表格 + 六类角色报告；不做看板、矩阵、多次考试趋势 |
| R15 | 结果只能从评价任务进入 |
| R16 | 学校管理员只读，唯一写操作是修改本人密码 |
| R17 | 基础数据不提供独立新增/编辑/删除入口，只能通过导入差异确认更新；新增年级、学校管理除外 |
| R18 | 科目按学段写死，不提供科目管理 |

| R20 | 考试与评价任务只能引用已保存版本，未保存编辑稿不可用 |
| R21 | 系统管理员基础数据先选学校、再选年级，不通过顶部切换学校 |

| R23 | 列表页不展示无意义的汇总统计卡，只保留业务操作与数据列表 |
| R24 | 保存版本必须复制学生、班级、教师、任课关系为只读快照 |
| R25 | 成绩重新导入不自动改写已完成评价任务的结果 |
| R26 | 算法参数必须参与计算，重算生成新的结果版本 |
| R27 | 基础数据更新默认存为新版本；取消勾选必须提示并覆盖当前版本；被引用版本不可覆盖 |
| R28 | 仅系统管理员可删除版本；当前版本、被考试或评价任务引用的版本不可删除；历史版本可删除 |
