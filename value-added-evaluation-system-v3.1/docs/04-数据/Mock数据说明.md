## 3. 科目口径

本期把源数据的“外语”拆成三个独立科目：

- 英语
- 日语
- 俄语

每个学生只考其中一个；“外语”只作为分组标签，不再作为成绩科目。

| 科目 | 类型 | 计分 |
|---|---|---|
| 语文、数学 | 必考 | 原始分 |
| 英语、日语、俄语 | 必考（三选一） | 原始分 |
| 物理、历史 | 首选 | 赋分优先，缺失回退原始分 |
| 化学、生物、政治、地理 | 再选 | 赋分 |

每个学生六科：

```text
语文 + 数学 + 英语/日语/俄语（三选一） + 物理/历史（二选一） + 再选两科
```

## 4. 数据清洗规则

| 处理 | 说明 |
|---|---|
| 班级名统一 | 统一为“高三1班 / 高二1班” |
| 排除临时班级 | 致远“临时班级”不导入 |
| 排除空班 | 弘知“高三20班”只有教师、没有学生，不导入 |
| 排除占位教师 | 弘知“懂你 / 0755-101605”不作为真实教师 |
| 排除非高考科目 | 博雅 1 条“德语”任课记录不导入 |
| 教师工号 | 不导入手机号，按学校重新生成（如 BY001） |
| 学生姓名/学号 | 使用真实值（本期选择 5B 全量真实） |
| 无成绩学生 | 保留学生记录，不生成成绩记录 |
| 缺考 | 学生选科确定但该科无成绩时，成绩记录标记“缺考” |
| 同名 | 按学号匹配，不按姓名 |
| 学籍号 | 源表学籍号列为空，使用学号作为业务主键 |

## 6. 评价任务

预置任务：

| 项目 | 内容 |
|---|---|
| 任务 | 高中园四校增值评价（高二期末 → 高三） |
| 入口 / 评价 | E1 高二期末 / E2 高三 |
| 学校 | 博雅、弘知、理工、致远 |
| 版本 | 各校 V2 当前版本 |
| 算法 | 标准分增值法，9 档，保持阈值 0.25，步长 0.5，结果版本 R4 |
| 口径 | 逐条成绩优先赋分；赋分缺失回退原始分 |
| 部分缺考 | 整生剔除（任务参数，可改为仅剔除该科） |
| 可计算样本 | 2,496 人 |
| 剔除 | 316 人 |

匹配统计：

| 项目 | 数量 |
|---|---:|
| 两场都有 | 2,794 |
| 两场六科完整 | 2,496 |
| 仅入口 | 99 |
| 仅评价 | 18 |
| 成绩不完整（含外语变更） | 298 |
| 其中外语语种变更 | 1 |
| 班级号变更 | 2,322 |
| 教师任课缺失 | 0 条成绩 |

说明：

- 赋分逐条优先；赋分缺失的个别记录回退原始分；
- 教师任课缺失的成绩不进入教师结果；
- 四类结果可从任务列表进入，支持科目切换、筛选、分页和 CSV 导出；
- 结果页提供“计算过程”辅助页，逐步展示数据口径、联考均值/标准差、学生 z 分与等级、判定分布、四层汇总权重和；学生标准化列表可点击学生查看完整计算链路，四层汇总的班级行可点击查看班级完整汇总过程；
- 算法说明和示例演算已从计算过程移出，放在独立公开文档 `algorithm.html`（无需登录）和 Markdown 文档；公开版只使用虚构学生/班级，不含真实姓名、学号、学校、班级；计算过程只保留 1–5 步操作数据；
- 系统管理员“参数配置”页维护新建任务默认参数（9 档、阈值 0.25、步长 0.5、小样本 8、默认算法）；档位支持自定义配置；
- “数据与口径”统计在上，下方以 Tab 常驻展示正常样本（2,496）、学生异常（415）、成绩异常（0）三张清单；学生异常可按仅入口/仅评价/未满六科/外语变更过滤。
