## 2. 快速开始

### 查看需求

```text
docs/00-文档索引.md
docs/01-需求/PRD-v3.1-成绩增值评价系统.md
```

### 打开首页与系统

直接双击：

```text
prototype/index.html      # 首页（登录页）
prototype/app.html        # 系统（登录后进入）
```

或启动静态服务：

```bash
cd prototype
python -m http.server 8099
```

访问 `http://localhost:8099` 进入首页，直接在页面输入账号密码登录；登录成功后进入 `app.html`。

## 4. 角色与演示

| 角色 | 权限 |
|---|---|
| 系统管理员 | 查看四校基础数据与考试成绩；维护学校、保存版本；新建并计算评价任务；维护默认参数 |
| 学校管理员 | 只读：查看本校基础数据、考试成绩与评价结果 |

- 首页登录后进入**基础数据**；
- 学校管理员演示账号默认绑定**博雅高中**；
- 评价任务已接入：任务列表、配置、匹配确认、算法参数、计算、四类结果；
- 任务列表“查看结果”旁新增“查看报告”；报告按区域/联考、校长、年级主任、班主任、科任教师、学生六个视角成页，含结论、指标、图表、名单与建议；
- 结果页可进入“计算过程”，查看统计量、学生 z 分/等级/判定、四层汇总的输入数据；样本与剔除下方以 Tab 展示正常样本、学生异常、成绩异常清单；
- 默认等级档数为 9 档；系统管理员可在“参数配置”维护默认档数、阈值、步长、小样本和算法；档位支持自定义配置；
- “算法说明”为独立公开文档（`prototype/algorithm.html`，无需登录）和 Markdown 文档，包含权重专章、9 档规则、公式文字解释、四层汇总和虚构学生/班级完整示例；公开版不含任何真实学生/学校数据；
- 基础数据导入、成绩导入向导入口已隐藏，数据由构建脚本预置。

数据由 `prototype/tools/build_dataset.py` 从 `高中园/*.xls` 生成，输出：

```text
prototype/assets/js/mock/dataset.js
```

- 学生姓名、学号、教师姓名使用真实值；
- 教师手机号/账号不写入原型，工号重新生成；
- 外语拆分为英语、日语、俄语三个独立科目；
- 数据仅限内部演示，含真实个人信息，请勿公开传播。
