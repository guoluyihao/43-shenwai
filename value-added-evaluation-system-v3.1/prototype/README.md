# 增值评价系统 · 原型（高中园数据与评价任务版）

> 本期包含：深圳外国语学校高中园四校的**基础数据**、**两场成绩数据**、**评价任务（四类结果）**与**七类角色报告**。
> 不含独立看板与多次考试趋势；报告内提供四象限矩阵与等级迁移图。

## 1. 打开

直接双击 `index.html` 打开首页兼登录页，输入账号密码后进入 `app.html`；已登录时也可直接双击 `app.html`。

> 界面（v3.3）：**数据分析报告**式科技风——纸面正文、深色封面、等宽数字、图注编号；登录首屏与报告封面为深色重音。详见 [视觉方案-v3.3](../docs/03-设计/视觉方案-v3.3-数据分析报告.md)。

或启动静态服务：

```bash
cd prototype
python -m http.server 8099
```

访问 `http://localhost:8099` 为首页（登录页）；登录后进入系统 `app.html`。

## 2. 本期范围

### 已导入

- 4 所学校：博雅高中、弘知高中、理工高中、致远高中；
- 每校 1 个实际年级：2027 届高三（2024 入学）；
- 每校 2 个版本：V1 高二期末快照、V2 高三当前；
- 当前 59 个班、2,812 名学生；
- 202 名任课教师；
- 2 场考试：2024 级高二期末（入口）、2024 级高三（评价）；
- 约 3.28 万条成绩记录，含原始分、赋分、缺考标记；
- 8 条按学校拆分的成绩导入记录。

### 已接入

- 评价任务列表；预置 1 个已完成四校联考任务（可计算样本 2,496 人）；
- 新建任务 → 配置 → 匹配确认 → 算法参数 → 计算 → 四类结果；
- 学生、班级、教师、学校四张结果表，支持科目切换、筛选、分页、CSV 导出；
- 任务列表“查看结果”旁新增“查看报告”：区域/联考、校长、年级主任、学科组长、班主任、科任教师、学生七页，含深色报告封面、四层报告块、自动解读、四象限/等级迁移/等级流向/各科堆叠条，每张图下配对应数据表；班级矩阵直接标注全部班级名称；
- 报告只读结果版本，支持对象切换（学校/班级/科目/教师/学生）与浏览器打印；学校管理员锁定本校；
- 报告统一四层：L1 结论摘要（一句话结论 + 三个关键数 + 发现/风险/亮点/建议）→ L2 证据块（问题式标题 → 一句话发现 → 图/表全宽 → 图下三列解读“读法/提示/动作”）→ L3 行动 → L4 补充明细与数据质量（只放正文未展开的表，始终展开）；关键数字用蓝/红/绿高亮；象限四色、关注标签五色；G1 最高（最好、绿色）、G9 最低（最弱、红色），所有迁移图和等级结构都写明方向；每个槽位固定“重点关注 / 关注 / 正常 / 较好”状态，不因数据好坏改变结构；
- 报告开头固定“本考试报告说明”：考试任务、入口/评价考试、统计范围与样本、计算过程（标准分/划档/跨档贡献/合成）、8 个重点指标说明、阅读与颜色说明；打印时作为报告首页；
- 总—分同构下钻：全校等级迁移下方直接给“按班看迁移”小多图，按低档净增排序、前 3 个班标红，点班展开同款迁移；班级矩阵、学科表、热点矩阵、名单沿用同一范围条与高亮规则；
- 新增“学科组长”报告：备课组长/教研组长从全校看一门学科，含全校学科位置、班级分布、教师差异、等级迁移、关注名单与行动；顶部可切学科，并可切“学科汇总 / 某教师”看该教师所教班清单；
- 科任报告支持“教师汇总 / 单班”切换：汇总页含两张分班对比卡、分班全表与合并名单；单班视图只算本班，给出单班结论、本班扫描、本班名单和本班行动；结论里的班级名可直接点击切换；
- 结论与解读中的科目/班级名称可点击：点击后不跳页，顶部出现“分析定位”条，滚动到对应区块并高亮目标行/单元格，可一键清除；区域报告扩为 9 块（格局、指标差异、差距、学科热力、等级结构、正向发现、行动、质量）；
- L4 增加“全量宽表”：班级一行同时看总分与各科（增值 + 退步/掉档），学生一行同时看总分与六科（入口档→评价档 + Δz）；结果页保留快速查询，完整宽表以报告 L4 为准；
- 区域/联考、校长、年级主任、学科组长、班主任、科任教师、学生七类报告均已按同一四层骨架改造；范围与隐私各自裁剪：区域不含学生姓名，班主任仅本班，科任仅本科/所教班，学生仅本人；
- 班主任页可切班级、科任页可切科目/教师、学生页可切班级/学生，并支持按姓名/学号检索学生；切换后整页与附录重算并回到页首；选项按账号权限过滤（管理员/学校管理员全量，其他角色仅授权对象），PDF 导出当前选择。
- 校长/年级“补充明细与数据质量”只放正文未展开的四校总表、四校×学科、方向、完整矩阵、完整名单与数据质量；正文图下已展开的入口段/班级/学科/流向表不重复；支持全量数据 CSV 导出；
- 全科目固定顺序：语文、数学、英语、物理、历史、化学、生物、政治、地理、日语、俄语；学生个人六科按“外语、首选”实际科目排列；
- 报告为静态文档：正文不含筛选控件；结论关键词可页内定位，不改变计算口径；L4 明细层始终展开；右侧目录导航 + 滚动高亮，支持“导出 PDF”（浏览器打印，A4 纵向，附录随主报告一起导出）；
- 匹配异常基于真实数据生成：仅入口 99、仅评价 18、成绩不完整 297、外语科目变更 1、班级变更 2,322、教师任课缺失 0（理工6/8班政治已补王雅薇）。

### 本期不做

- 教师看板、学生矩阵、多次考试趋势；
- 服务端 PDF 生成（浏览器“导出 PDF”可用）；
- 成绩上传/重新导入向导（入口已隐藏，数据已预置）；
- 基础数据导入向导（入口已隐藏，数据已预置）。

## 5. 数据说明

- 数据由 `tools/build_dataset.py` 从 `高中园/*.xls` 生成，输出 `assets/js/mock/dataset.js`。
- 学校、年级、班级、学生、教师、任课、版本、考试、成绩均为真实数据。
- 学生姓名、学号、教师姓名使用真实值；教师手机号/账号不写入原型，工号按学校重新生成。
- 外语按源数据拆为**英语、日语、俄语**三个独立科目；每个学生只考其中一个，“外语”只作分组标签。
- 逐条成绩优先赋分，赋分缺失时回退原始分；物理/历史当前源表无赋分，因此使用原始分。
- 数据仅限内部演示，含真实个人信息，请勿公开传播。

## 6. 演示路线

1. 首页输入账号密码登录 → 基础数据 → 选择博雅高中 → 2027 届高三 → 查看班级/版本；
2. 打开高三 14 班，查看日语/俄语教师与学生名单；
3. 基础数据 → 教师 Tab，查看 63 名教师及任教学科；
4. 考试管理 → 打开高二期末或高三考试 → 查看学生单行成绩单、分页、姓名/学号检索与导入记录；
5. 评价任务 → 打开预置任务查看四类结果；或新建任务走“配置 → 匹配 → 算法 → 计算”；
6. 结果页切换学生/班级/教师/学校 Tab，切换科目，导出 CSV；
7. 结果页或任务列表点“查看报告”，依次查看区域/校长/年级主任/学科组长/班主任/科任教师/学生七页，切换学校/班级/科目/教师/学生；
8. 结果页 → “计算过程”，逐步查看数据口径、联考统计、学生标准化、等级判定、四层汇总；在“学生标准化”列表点击学生姓名或“查看计算”，查看该生从原始输入、赋分采用、z/等级/判定到总分和汇总贡献的完整链路；在“四层汇总 → 班级”点击班级名称或“查看计算”，查看班级成员逐人贡献和汇总公式代入；在“数据与口径”下方用 Tab 查看正常样本、学生异常、成绩异常清单；
9. 系统管理员 → “参数配置”，维护默认 9 档、阈值、步长、小样本和默认算法；
10. 帮助 → “算法说明”，查看独立完整文档（含 9 档规则、学生/班级完整示例）。
