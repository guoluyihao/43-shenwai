# 打包说明

## 0. 本期原型范围

本期原型包含：**高中园四校基础数据 + 高二期末/高三两场成绩 + 评价任务（四类结果）**。
不包含独立增值报告、图表、看板与矩阵；评价任务支持新建、配置、匹配、算法、计算与结果查看。

## 1. 打包范围

本包包含：

```text
value-added-evaluation-system-v3.1/
├── README.md
├── 打包说明.md
├── docs/
└── prototype/
```

说明：

- `docs/` 包含完整 v3.1 文档库，以及部署文档和历史归档。
- `prototype/` 包含原型入口、样式、脚本和 Mock 数据。
- 不包含 `score-manager/` 旧版系统代码。
- 不包含 `.git/`、JDK、Maven、Excel、PDF 等与本交付无关的文件。

## 2. 本轮文档与原型一致性检查

已重点核对并对齐：

- 基础数据层级：学校 → 实际年级（版本）→ 班级 → 学生/班主任/科任；教师单列。
- 基础数据导入后的版本流程：
  - 差异确认后先弹出更新确认；
  - 默认“存为新版本”；
  - 取消勾选时二次确认覆盖当前版本；
  - 当前版本被引用时不可覆盖；
  - 当前无版本时必须存为新版本。
- 版本管理：
  - 当前版本不可删除；
  - 被考试/评价任务引用的版本不可删除；
  - 未被引用的历史版本可删除；
  - 删除版本不影响当前数据。
- 新增考试必须显式选择学校，不默认勾选；自动带出实际年级与最新已保存版本。
- 成绩导入按考试加锁、按学校覆盖；已完成评价结果不被重导自动改写。
- 评价任务按校选版本；参数参与计算；新建任务生成独立结果，不覆盖历史任务。
- 结果字段：
  - 学生：联考排名；
  - 班级：进步占比、退步占比；
  - 教师：任教班级、进步占比；
  - 学校：退步占比，指标与班级一致。
- 学校管理员只读；除修改本人密码外，写操作入口隐藏；结果支持 CSV 导出。
- 单边学校、入口/评价版本不一致会进入匹配异常清单。

## 3. 已验证项

- 所有原型 JS 文件通过 `node --check` 语法检查。
- 管理端 19 个页面路由（含计算过程辅助页）无空白页，无 `undefined`、`NaN`、`[object` 等异常文本；公开算法说明 `algorithm.html` 可免登录打开。
- 系统管理员与学校管理员菜单、权限、写操作入口符合角色规则。
- 版本更新确认、默认存新版本、覆盖当前版本、被引用版本锁定、版本删除均已实际操作验证。
- 新建评价任务生成独立任务与结果，历史任务结果不被覆盖。
- 9 档参数可实际影响计算结果。
- 四张结果表的字段与需求文档一致。
- 计算过程页按数据口径、联考统计、学生标准化、等级判定、四层汇总逐步展示过程数据；样本与剔除下方以 Tab 展示正常样本、学生异常、成绩异常清单，学生异常可按类型过滤；
- 独立“算法说明”页面/文档包含 9 档规则、公式、四层汇总和学生/班级完整示例；系统管理员“参数配置”页面维护新建任务默认参数。
- 六类角色报告可从任务列表/结果页进入，六页可切换；结论、指标、名单与结果页数字一致，小样本与口径脚注齐全。
- CSV 导出可生成当前结果文件。

## 4. 已知限制

- 本期原型已接入评价任务、匹配、计算、四层结果与六类角色报告；报告含结论、指标、内联 SVG 图表、名单与建议，不含看板、矩阵与多次考试趋势。
- 成绩上传/重新导入向导、基础数据导入向导入口已隐藏，数据由构建脚本预置。
- 原型为纯静态演示，无后端、无真实 AI 服务。
- 数据含真实学生姓名/学号、教师姓名；教师手机号未写入；仅限内部演示，请勿公开传播。
- 外语按源数据拆为英语、日语、俄语三个独立科目；初中暂无数据。
- 登录在首页完成，账号密码由本地演示账号表校验；不接真实后端。
