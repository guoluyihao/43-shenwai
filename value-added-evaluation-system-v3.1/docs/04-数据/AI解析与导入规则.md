# AI 解析与导入规则 v3.1

## 1. 两类导入

| 类型 | 文档 | 结果 |
|---|---|---|
| 基础数据导入 | 学生名单、教师名单、任课安排 | 更新时默认存为新版本；取消勾选则覆盖当前版本 |
| 成绩导入 | 成绩单 | 按学校覆盖成绩，不做统计 |

文件类型：Excel（.xlsx/.xls）、CSV。

## 2. 基础数据解析

### 2.1 学生名单

- 学号、姓名、班级、选科、状态。
- 按“学校 + 实际年级”匹配；学号优先。
- 新增/缺失/班级变更/选科变更进入差异清单；缺失学生标记转出，班级不存在时自动创建。

### 2.2 教师名单

- 工号、姓名、学科、状态。
- 学科必须属于该学段固定科目。

### 2.3 任课安排

- 教师、班级、科目、是否班主任/主责。
- 班主任变更、任课变更进入差异清单，确认后真正更新教师库与任课关系。

### 2.4 更新规则

- 差异确认后点击“更新当前编辑稿”，先弹出更新确认。
- “存为新版本”默认勾选：应用差异后生成包含更新后数据的新版本，旧当前版本转已停用。
- 取消勾选：二次确认后覆盖当前版本，不新增版本；被引用版本不可覆盖。
- 当前无已保存版本时，必须存为新版本。
- 未保存编辑稿不能用于考试/评价。
- 版本删除：仅系统管理员可操作；当前版本、被引用版本不可删；历史未引用版本可删。

## 3. 成绩解析

- 学号、姓名、学校、班级、科目、原始分、高考赋分、缺考。
- 按考试配置的学校/实际年级/已保存版本匹配。
- 差异分级：阻断、待确认、提示。
- 同一考试同一时间只允许一个导入任务。
- 按学校覆盖；未涉及学校不变。
- 入库后只保存成绩，不做统计。

## 4. 置信度

| 等级 | 条件 | 处理 |
|---|---|---|
| 高 | ≥ 90% | 默认可接受 |
| 中 | 80% ~ 90% | 提示，可批量确认 |
| 低 | < 80% | 必须逐格确认 |

## 5. 字段归一

- 学号：去空格、全半角。
- 姓名：去空格、去括号备注。
- 班级：“高三1班/高三(1)班”统一。
- 科目：按学段固定科目与别名归一。
- 分数：去单位、识别缺考。
- 赋分：与原始分分列，无值留空。

## 6. 差异分级

| 级别 | 示例 | 处理 |
|---|---|---|
| 阻断 | 无法识别、重复、越界、文件损坏 | 逐条处理 |
| 待确认 | 新增/缺失、班级变更、选科变更、任课变更、赋分缺失 | 逐条或批量 |
| 提示 | 低置信度、别名、格式 | 批量接受 |

## 7. 失败与兜底

| 场景 | 处理 |
|---|---|
| 文件损坏 | 阻断，重新上传 |
| 无表格结构 | 阻断，检查文件 |
| 学校/实际年级无法识别 | 人工选择 |
| 学生无法匹配 | 阻断，人工关联或排除 |
| 已有导入任务 | 阻止新任务 |
| 覆盖旧数据 | 入库前明确提示 |
