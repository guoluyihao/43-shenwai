# 报告解读模板 v2.1

## 1. 报告结构

| 段落 | 内容 | 数据来源 |
|---|---|---|
| 一、评价概况 | 学校、年级、范围、两次考试、样本量、口径、算法、参数 | 评价任务 |
| 二、总体结论 | 整体进步/退步态势、进步面、退步面 | 学生结果汇总 |
| 三、学科表现 | 各科相对进步率、强弱科、异常科目 | 学科统计 |
| 四、班级表现 | 领先班级、进步显著班级、需关注班级 | 班级评价 |
| 五、教师表现 | 领先教师、进步显著教师、需关注教师 | 教师评价 |
| 六、学生群体 | 进步/保持/退步分布、高分段与低分段变化 | 学生结果 |
| 七、数据质量 | 匹配剔除、赋分缺失、样本不足、极端值 | 匹配报告与任务 |
| 八、建议 | 教学、管理、后续评价建议 | 规则生成 + 人工编辑 |

## 2. 写作原则

- 先事实、后判断、再建议。
- 每条结论必须能对应到数据。
- 不做无依据的因果推断，不评价教师个人能力。
- 排名必须注明范围与口径。
- 样本不足时先提示局限，再给结论。
- 语言客观、克制，避免夸张。

## 3. 规则话术

### 3.1 总体

| 条件 | 话术 |
|---|---|
| 相对进步率 > 1.1 且进步占比 > 40% | 本次评价整体呈上升态势，进步面较广，多数学生相对位置有所提升。 |
| 0.9 ≤ 相对进步率 ≤ 1.1 | 本次评价整体保持稳定，进步与退步基本平衡。 |
| 相对进步率 < 0.9 且退步占比 > 40% | 本次评价整体承压，退步面偏大，建议重点关注中低分段学生的稳定性。 |
| 平均进退步级数 > 0.5 | 学生整体位置变化幅度较大，分化明显。 |
| 平均进退步级数 < −0.5 | 学生整体位置下滑明显，需结合试卷难度与教学进度分析。 |

### 3.2 学科

| 条件 | 话术 |
|---|---|
| 某科相对进步率高于全体均值 20% 以上 | 本科目相对进步率明显高于平均水平，是本轮评价的亮点。 |
| 某科相对进步率低于全体均值 20% 以上 | 本科目相对进步率低于平均水平，建议结合试卷难度、教学进度与作业反馈进一步分析。 |
| 某科退步学生占比 > 50% | 本科目退步面偏大，建议优先关注基础薄弱学生的稳定性。 |
| 某科进步学生占比 > 50% | 本科目进步面较广，建议总结可复制的教学做法。 |
| 赋分缺失 | 本科目因赋分缺失，已按原始分计算，跨科目比较需谨慎。 |

### 3.3 班级

| 条件 | 话术 |
|---|---|
| 进步率排名前 3 | 该班本轮相对进步率位居前列，进步面较广。 |
| 进步率排名后 3 | 该班本轮相对进步率靠后，建议重点关注退步学生与学科短板。 |
| 实力排名前 3 且进步率中游 | 该班整体实力较强，但增值幅度一般，建议关注“高位保持”。 |
| 实力排名靠后但进步率靠前 | 该班起点较低但提升明显，增值表现突出。 |
| 样本不足 | 该班参与计算人数不足 8 人，排名与结论仅供参考。 |

### 3.4 教师

| 条件 | 话术 |
|---|---|
| 进步率排名前 3 | 该教师本轮相对进步率位居前列，所教班级进步面较广。 |
| 进步率排名后 3 | 该教师本轮相对进步率靠后，建议结合班级起点与学科特点综合分析。 |
| 所教班级差异大 | 该教师所教班级之间进步率差异较大，建议关注班级间的教学一致性。 |
| 任教班级样本不足 | 该教师部分任教班级样本不足，排名参考价值有限。 |

### 3.5 学生群体

| 条件 | 话术 |
|---|---|
| 高分段退步占比高 | 高分段学生出现流失迹象，建议关注尖子生群体的稳定性与心理状态。 |
| 低分段进步占比高 | 低分段学生提升明显，说明基础巩固措施初见成效。 |
| 保持占比 > 50% | 多数学生位置保持稳定，整体格局变化不大。 |
| 两极分化加剧 | 进步与退步两端占比同时上升，建议关注分层教学与个别辅导。 |

### 3.6 数据质量

| 条件 | 话术 |
|---|---|
| 剔除人数 > 5% | 本次评价剔除 X 人（占 Y%），主要原因为转学、缺考与信息不一致，结论代表性可能受影响。 |
| 赋分缺失 | X 科目赋分缺失，已整科回退原始分，请谨慎进行跨科目比较。 |
| 样本不足 | 共有 X 个对象样本不足 8 人，未参与排名。 |
| 存在极端值 | 数据中存在极端分数，已保留参与计算，建议核对原始成绩。 |
| 低置信度导入 | 本次导入有 X 个字段经人工修正，数据质量总体可控。 |

## 4. 建议模板

| 方向 | 建议 |
|---|---|
| 学科教学 | 对退步面较大的学科，建议开展试卷分析、错题归因与分层作业。 |
| 班级管理 | 对进步率靠后的班级，建议结合班情分析学习习惯、作业完成与课堂参与。 |
| 教师支持 | 对进步显著的教师，建议总结课堂做法并在教研组内分享。 |
| 学生关注 | 对高分段退步与低分段持续退步的学生，建议建立个别关注清单。 |
| 后续评价 | 建议在下次考试后复用同一基础数据版本与口径，保证可比性。 |

## 5. 报告尾部

- 数据口径：原始分 / 高考赋分（逐科说明）
- 算法：标准分增值法 / 等级差法
- 参数：等级档数、保持阈值、步长、小样本阈值
- 样本：参与人数、剔除人数、样本不足对象
- 生成时间、结果版本、编辑记录
