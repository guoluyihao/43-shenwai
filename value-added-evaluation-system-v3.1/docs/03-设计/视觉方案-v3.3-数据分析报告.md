# 视觉方案：数据分析报告式科技风（v3.3）

> 2026-10-25。本版把原型从「后台台账 + 浅色卡片」升级为**数据分析报告**：纸面阅读、章节叙事、图表为主角，科技感来自刻度、等宽数字与克制的电光蓝，而不是发光边框和驾驶舱装饰。
> v3.2 的浅色基线仍然有效，本文件描述 v3.3 的增量与替代关系。
> **2026-10-26 补充**：首页 `index.html` 改为**浅色清新科技**（见 [§7](#7-20261026-首页改版v34-清新科技)），§3.1 深色封面方案仅保留为历史记录；后台 `app.html`、报告与打印仍按本文件执行。

## 1. 目标与边界

- **对象**：登录/价值页 `index.html`、后台 `app.html` 全部路由、公开算法页 `algorithm.html`、六类报告与打印。
- **只改视觉与少量模板容器**：不改路由、数据结构、算法口径、权限、导出与打印逻辑。
- **阅读优先**：表格仍是 13px 级密度；深色只用于封面/登录首屏，正文、表格、图表、打印一律纸面。
- **科技感的落点**：细网格/刻度、等宽数字、图注编号、报告封面、四象限与分布图；不使用霓虹光晕、HUD 角标、扫描线。

### 3.4 六类报告：四层 + 报告块（v3.4 增补）

- 每份报告新增深色 `report-cover`：报告类型、标题、读者范围、任务、口径、样本、版本、角色标签。
- 正文统一为四层，不再是一条长文：

| 层级 | 内容 | 交互 |
|---|---|---|
| L1 结论层 | 一句话结论 + 3 个关键数 + 发现/风险/亮点/建议 + “继续看”导航 | 屏幕首屏；打印独立成第一页 |
| L2 证据层 | 3–5 个报告块，每块回答一个问题 | 图/表全宽；解读在图下横向三列（读法 / 提示 / 动作） |
| L3 行动层 | 教学 / 班级管理 / 两周后复查 | 与证据块同一视觉体系，不另做卡片 |
| L4 明细层 | 只放正文未展开的补充表 + 数据质量 | 始终展开；内部按 A–D 分块并逐块解读 |

- 每个报告块固定骨架：编号 → 层级/英文眉标 → 问题式标题 → 一句话发现 → 图/表（全宽）→ 图下三列解读（读法 / 提示 / 动作）→ 页脚（来源、核对入口）。
- 解读文字由报告内已有指标生成，不新增计算口径；统一用“说明 / 提示 / 需要核实”，不下因果结论。
- 关键数字高亮：关键数字用数据蓝；退步/拖累用红、进步/优势用绿，每段最多 1–2 处；结论层三个大数统一主色。
- 每张图下配对应数据表（图 N / 表 N）：等级迁移、班级矩阵、入口段、所教班、六科 Δz 均可在图下直接核对原始数值。
- 恢复两张关键图：**入口第几档 → 现在第几档**流向矩阵（校长/年级，独立“等级流向”块）与**各科进步/保持/退步**堆叠条（学科结构块顶部），不再只留在明细表里。
- 七份报告块数：区域 9 块，校长/年级 9 块，班主任 6 块，科任 6 块（另有单班视图 5 块），学科组长 6 块，学生 3 块；L4 只保留正文未展开的内容（区域仅数据质量，班主任仅学生名单，科任/学生不再单列 L4），避免与图下表重复。
- 每份报告开头固定“本考试报告说明”：考试任务与入口/评价考试、统计范围与样本、计算过程（标准分/划档/跨档贡献/合成）、8 个重点指标说明、阅读与颜色说明；打印时作为报告首页。
- 总—分同构下钻：全校等级迁移下方直接给“按班看迁移”小多图，按低档净增排序、前 3 个班标红，点班展开同款迁移图；班级矩阵/学科表/热点矩阵/名单沿用同一范围条与高亮规则。
- 科任报告双视图：顶部“教师汇总 / 班1 / 班2”切换；汇总页含两张分班对比卡和分班全表，单班视图只算本班并给出单班结论、本班扫描、本班名单和本班行动。
- 新增“学科组长”报告：备课组长/教研组长从全校看一门学科，含全校学科位置、班级分布、教师差异、等级迁移、关注名单与行动；顶部可切学科，并可切“学科汇总 / 某教师”看该教师所教班清单。
- 等级方向统一写清：G1 最高（最好，Z>1.75、权重 90），G9 最低（最弱，Z≤−1.75、权重 10）；G1 > G2 > … > G9。迁移色阶用绿→黄→红，G1 绿、G9 红，避免“颜色很好看、方向读反”。
- 结论与解读中的科目、班级名称可点击：点击后不跳页，顶部出现“分析定位”条，页面滚动到对应区块并高亮目标行/单元格；“班级”点击在科任页直接切到单班视图。
- 区域报告补强：关键指标差异表（含区域均值与极差）、差异聚焦、学科 × 学校热力表、四校 G1–G9 占比变化柱图、正向发现；重点回答“关键指标差异落在哪所学校/哪一科”。
- L4 增加“全量宽表”：班级一行同时看总分与各科（增值 + 退步/掉档），学生一行同时看总分与六科（入口档→评价档 + Δz）；结果页保留快速查询，完整宽表以报告 L4 为准。
- 表格统一：报告内所有表共用表头底色、字号、行高、边框和数字对齐；不再使用 `max-height` 内部滚动框，表格直接随页面展开；关键状态用颜色区分——象限四色（双高绿 / 低进高出蓝 / 高位承压橙 / 相对靠后红），关注标签五色（总分2档红 / 入口靠前橙 / 单科2档紫 / 单科4档深红 / 总分退步灰）。
- 四象限保留均值/1.0 参考线与“双高 / 低进高出 / 高位承压 / 相对靠后”语义；极端值贴顶显示并标 `↑`，图注注明实际值。
- 新增报告级图表：
  1. **四校实力 × 增值矩阵**（区域页）：x=学业实力，y=相对进步率；
  2. **班级实力 × 增值矩阵**（校长/年级页）：气泡=班级人数，焦点班青色高亮；**全部班级名称直接标注在点旁**，不做引线、不使用编号替代，图下再配完整班表；
  3. **入口 → 评价 等级分布迁移**（校长/年级/班主任页）：G1–G9 双向分布条 + Δ 人数；
  4. **入口第几档 → 现在第几档**（校长/年级）：9×9 流向矩阵 + 主要流向文字；
  5. **各科进步 / 保持 / 退步**（校长/年级）：堆叠条 + 学科全表；
  6. **所教班本科增值**（科任页）：横向条 + 1.0 平衡线；汇总页加分班对比卡，单班视图高亮当前班；
  7. **关键指标差异**（区域页）：四校指标表 + 区域均值 + 极差条形；
  8. **四校等级结构变化**（区域页）：每校 G1–G9 的“评价占比 − 入口占比”发散柱，绿=改善、红=恶化；
  9. **正向发现**（区域页）：达到平衡、进步面、优势学科、低进高出。
- 扫描表从 5 列压缩为“标签 + 结论/对比/脚注”；图表按全宽 760×560（全部标签）定标，解读区在图下三列，不再占用右侧栏。

## 7. 2026-10-26 首页改版（v3.4 清新科技）

> 目标：首页要更有科技感，但**不要太黑**——浅色清新，同时有节奏感。只改 `index.html` + `assets/css/home.css`，文案、章节顺序、1.3 倍字号体系、登录链路不动。

### 7.1 与 v3.3 的差异

| 维度 | v3.3（§3.1） | v3.4 |
|---|---|---|
| 首屏 | 深色封面 `#070d18` + 玻璃卡 | 浅冷白渐变 `#ffffff → #e8f3fa` + 白色玻璃卡 |
| 深色使用 | 封面、收尾、页脚 | 全页无深色块；仅墨色文字与细线 |
| 科技感来源 | 深底网格 + 青色光 | 刻度尺、双层网格、等宽数字、柔和青蓝光晕 |
| 动效 | 基本无 | 首屏入场 + 块内错峰 + 块间扫线 + 数字滚动 + 进度刻度 |
| HUD 元素 | 规范禁止 | 允许在首屏克制使用（四角刻线、发丝线、刻度） |

### 7.2 色板

- 底：`#ffffff → #f5fbfd → #e8f3fa`；区块交替 `#ffffff` / `#f7fbfd` / `#f2fafd`
- 主色 `#1f4fd8`；科技青 `#0891b2`，深青文字 `#0e7490`（小字对比度 ≥ 4.5:1）
- 墨色 `#0a1220` / 正文 `#45566e` / 弱化 `#6b7c93`
- 线 `#e2ebf5`；网格 `rgba(31,79,216,.045)`（细格 40px、刻度格 200px）
- 9 档色带改为青蓝连续标尺：`#0b3566 → #e3f7fb`

### 7.3 首屏结构

1. 装饰层：细网格 + 200px 刻度格（`mask` 向下淡出）、两团呼吸光晕（青 / 蓝，9s / 13s）。
2. 左栏：等宽眉标（脉冲点 + 发丝线）→ 主标题（第二行青蓝渐变）→ 3 条价值点 → **联考位置刻度尺**（−3σ…+3σ，标记点落在 +1σ，Δz 段从 0 展开）→ 三个 KPI（数字滚动）→ 适用范围。
3. 右栏：登录卡，顶部蓝→青渐变细线、四角刻线、白玻璃底、按钮 hover 高光扫过。
4. 底部**数据条**：系统快照（2 个时间点 / 4 层结果 / 9 档等级 / 0.25σ 保持阈值 / 8 人排名下限），数字滚动，右端标注“示意数据”。

### 7.4 章节与进度

- 每个区块加等宽序号（CSS counter，`01 | 为什么`）。
- 右侧固定**进度刻度**（≥1280px 显示，11 段，当前区块青线加长并发光），点击可跳转。
- 卡片统一：白底 + 1px 细边 + hover 上浮 2px + 青边 + 柔影；四层卡片右上角带淡青光斑。

### 7.5 动效规范

| 层级 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 微交互 | 120ms | `ease-out` | hover / focus / 按钮 |
| 元素入场 | 420ms | `cubic-bezier(.22,.61,.36,1)` | 位移 14px + 淡入 |
| 区块入场 | 560ms | 同上 | 顶部发丝线 `scaleX` 扫过 |
| 块间推移 | 900ms | `cubic-bezier(.65,0,.35,1)` | 240px 高青蓝渐变带横向掠过，结束即透明 |
| 氛围循环 | 9 / 13 / 28s | `ease-in-out` | 光晕呼吸、网格缓移 |

- **块内节拍**：kicker 0ms → h2 +70ms → lead +140ms → 卡片组每张 +70ms（上限 460ms）→ 注释收尾。
- **首屏入场**：眉标 40ms → 标题 100ms → 正文 180ms → 价值点 260ms → 刻度尺 330ms → KPI 400ms → 说明 460ms；登录卡 220ms 起 660ms 升入；数据条 500ms 淡入。
- **数字滚动**：`easeOutCubic` 900ms，从 0 计到目标值（支持 2 位小数，如 0.25σ）。
- **触发**：`IntersectionObserver`，进入一次即停，不重复播放；滚动位置用 `requestAnimationFrame` 节流。
- **降级**：`prefers-reduced-motion: reduce` 时 `html` 不加 `.anim`，全部动效归零、内容直接呈现；`?anim=off` 用于截图与调试。
- **性能**：动效只动 `transform` / `opacity`（唯一的例外是刻度尺标记点用静态定位），不触发布局。

### 7.6 响应式与高度适配

- 1280 / 1366 / 1152 / 1440 与 768 / 390 均验证；`≥1280px` 显示进度刻度。
- 高度断点：`≤960px` 收紧字号与行距、隐藏适用范围；`≤800px` 收起刻度尺，保证登录卡与数据条在一屏（1366×768 实测 `overflow: 0`）。
