# 页面清单与信息架构 v3.1

## 1. 菜单

```
学校管理（系统管理员）
基础数据
考试管理
评价任务
参数配置（系统管理员）
帮助：算法说明
```

> 本期原型已开放**学校管理、基础数据、考试管理、评价任务、参数配置**；帮助区提供独立“算法说明”。首页登录后进入基础数据。导入向导为占位页。

登录后默认进入**评价任务**（完整版目标；本期原型为**基础数据**）。

## 2. 页面清单（19 个页面路由，含计算过程辅助页）

| # | 路由 | 页面 | 角色 | 目标 |
|---|---|---|---|---|
| 1 | `index.html` | 首页 / 登录 | 全部 | 直接输入账号密码，登录后进入系统 |
| 2 | `#/schools` | 学校管理 | 系统管理员 | 新增、启停、重置密码 |
| 3 | `#/basic` | 基础数据 | 全部（学校只读） | 学校列表 → 年级列表 → 班级/学生/教师/版本 |
| 4 | `#/basic/import` | 基础数据导入 | 系统管理员 | 学生名单/教师名单/任课安排 → AI 解析 → 差异确认 → 更新确认（默认存为新版本） |
| 5 | `#/exams` | 考试管理 | 全部（学校只读） | 考试列表、新增、详情、删除 |
| 6 | `#/exams/new` | 新增考试 | 系统管理员 | 学段 → 年级层次 → 点击“选择学校” → 自动带出实际年级与最新版本 |
| 7 | `#/exams/:id` | 考试详情 | 全部 | 学生单行成绩单（横向科目/总分、分页、姓名学号检索）+ 导入记录 |
| 8 | `#/import` | 成绩导入 | 系统管理员 | 成绩单 → 解析 → 匹配 → 差异 → 按校覆盖 |
| 9 | `#/evaluations` | 评价任务 | 全部 | 任务列表 |
| 10 | `#/evaluations/new/config` | 配置评价任务 | 系统管理员 | 两次考试、按校已保存版本、逐科口径 |
| 11 | `#/evaluations/new/match` | 匹配与确认 | 系统管理员 | 学校/学生/成绩异常 |
| 12 | `#/evaluations/new/algorithm` | 算法与计算 | 系统管理员 | 算法、参数、计算 |
| 13 | `#/evaluations/:id/results` | 评价结果 | 全部 | 学生/班级/教师/学校四张表 |
| 14 | `#/evaluations/:id/reports` | 报告入口 | 全部 | 六个角色视角卡片 + 报告说明 |
| 15 | `#/evaluations/:id/reports/:role` | 角色报告 | 全部（学校限本校） | 区域/校长/年级主任/班主任/科任教师/学生六页 |
| 16 | `#/evaluations/:id/process` | 计算过程（辅助页） | 全部 | 数据口径、联考统计、学生标准化（点击学生查看完整计算链路）、等级判定、四层汇总（点击班级查看完整汇总过程）、样本清单 |
| 17 | `#/settings` | 参数配置 | 系统管理员 | 默认 9 档、阈值、步长、小样本、部分缺考处理、默认算法；9 档 Z 区间/权重只读，支持自定义配置档位 |
| 18 | `#/algorithm` | 算法说明入口 | 全部 | 文档导读、9 档摘要、打开公开文档 |
| 19 | `algorithm.html` | 公开算法说明 | 所有人（无需登录） | 完整叙述：权重专章、公式文字解释、虚构学生/班级示例、结果解读 |

> 第 2–19 项的系统路由均位于 `app.html` 下，例如 `app.html#/basic`；登录在 `index.html` 完成。

## 3. 基础数据页面

```
基础数据
├── 学校列表（系统管理员）
│   └── 年级列表（可新增年级）
│       ├── 年级卡片：学段、年级层次、实际年级、班级数、学生数、当前版本、是否有未保存修改
│       └── 年级详情
│           ├── 当前编辑稿状态
│           ├── 导入更新（学生/教师/任课文档）
│           ├── 保存版本（手动备份）
│           ├── 版本列表（当前/历史，可删除未被引用版本）
│           └── 班级列表
│               └── 班级详情：学生 / 班主任 / 科任
└── 教师（单列，只读展示，通过导入更新）
```

- 没有“科目”Tab。
- 没有独立新增/删除按钮。
- 教师、学生、班级变化只能通过导入更新。
- 导入更新确认时默认“存为新版本”；取消勾选则提示覆盖当前版本。
- 当前版本、被考试/评价引用的版本不可删除；历史版本可由系统管理员删除。

## 4. 新增考试

```
新增考试
├── 基本信息：名称、时间
├── 学段：高中 / 初中
├── 年级层次：高三/高二/高一 或 初三/初二/初一
├── 点击“选择学校”：弹窗只显示该学段+年级层次下有实际年级的学校
├── 确认后才展示：每校实际年级 + 最新已保存版本
└── 科目：从学段固定科目中选择
```

- 同学段、同年级层次才能同场考试。
- 学校没有实际年级或没有已保存版本时不可选。

## 5. 评价任务

```
评价任务
├── 列表
├── 配置：入口/评价考试、按校已保存版本、口径
├── 匹配：学校/学生/成绩异常
├── 算法：标准分法/等级差法
├── 结果：学生 / 班级 / 教师 / 学校
└── 报告：区域 / 校长 / 年级主任 / 班主任 / 科任教师 / 学生
```

## 6. 结果页面

| Tab | 内容 | 排名范围 |
|---|---|---|
| 学生结果 | 学生 × 科目/总分、入口/评价、联考排名、等级变化、进退步 | 联考全体 |
| 班级结果 | 学校 + 班级、指标（含退步占比）、两套排名 | 校内 |
| 教师结果 | 学校 + 教师 + 科目、任教班级、指标（含进步占比）、两套排名 | 校内 |
| 学校结果 | 学校、指标（含退步占比）、两套排名（与班级指标一致） | 联考全体 |

- 结果页只做表格、筛选、分页、导出；图表、结论与建议放在独立角色报告页。
- 不做看板、矩阵、多次考试趋势。
