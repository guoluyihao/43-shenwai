# 增值分析报告结构规范（v1）

> 目的：定义“分析报告（新版）”的方法、骨架、章节模板与角色模块；旧报告代码保留但入口关闭。
> 适用范围：评价任务 → 分析报告入口 → 七个角色报告（区域/联考、校长、年级、学科、班主任、科任、学生）。
> 原则：章节中立、数据完整、解读双向、归因分级、角色只变范围与路径。

---

## 1. 方法：先定义“这件事”，再定义章节

| 要素 | 定义 | 对报告的要求 |
|---|---|---|
| 分析对象 | 同一批学生从入口到出口的**相对位置变化** | 不写“分数高低”，写“位置、变化、结构” |
| 比较集 | 同首选组 / 同联考 / 同入口段 / 同单位 | 每个数字必须注明“和谁比” |
| 单位 | 学生 → 班级 / 学科 / 教师 → 学校 / 区域 | 每个单位都有范围、样本、基准 |
| 度量 | 位置（学业实力）、变化（ΔZ/等级）、结构（分布/迁移）、差异（极差/方差）、关联（同向） | 每章用同一套镜头 |
| 证据 | 完整数据、n≥8、基准率、期望值、数据质量 | 不遗漏单位、不裁剪分布、不隐藏不利数据 |
| 解读 | 好 / 差 / 无显著变化；效应量 + 样本 | 双向，先描述后判断 |
| 归因 | L1 直接数据原因 / L2 机制 / L3 根本 | 报告只写到 L2；L3 标“候选/待验证” |
| 交付 | 完整版（全量 + 证据）/ 简易版（抽取） | 每章首屏可抽取 |

**读数基线**：全体 2,496 人 ΔZ 均值 −0.001、标准差 0.524；当前 ±0.25 口径下，稳定队列的退步面基线约 **31.7%**。报告必须先给基线，再给实际值。

---

## 2. 中立骨架

```
A 报告说明
B 总体
C 结构
D 分项（学校 / 学科 / 班级 / 教师 / 学生，按角色启用）
E 差异与关联
F 追问与行动
附录（全量数据 / 数据质量 / 指标字典）
```

- **A 报告说明**：基本情况、数据来源、算法逻辑、关键指标、怎么读。
- **B 总体**：范围、样本、位置、变化、退步/进步/保持，先给全貌。
- **C 结构**：入口到出口的等级分布与迁移。
- **D 分项**：按单位逐一完整呈现，不挑选。
- **E 差异与关联**：单位之间差多少、差异在均值还是分布、什么与好坏同向。
- **F 追问与行动**：好/差/无显著变化，分别追问原因，给行动与复查。
- **附录**：全量单位表、学生明细、数据质量、指标字典。

章节名保持中立，不使用“拖累、异常、问题、重点关注”等判断词；判断只出现在解读层。

---

## 3. 章模板（六段，顺序固定）

1. **数据**：该范围全部单位/全分布的表或图，带 n、基准、异常标记。
2. **读法**：这一章怎么读、基准是什么、哪些不能直接比。
3. **双向解读**：好 / 差 / 无显著变化，各列出来。
4. **追问**：为什么好、为什么差；L1/L2，L3 候选。
5. **边界**：这一章不能证明什么。
6. **行动**：好的怎么复制、差的怎么干预、两周后看什么。

## 5. 数据完整性规则

- **单位完整**：正文列出该角色范围内的全部学校/班级/学科/教师，不按“异常”筛选。
- **分布完整**：等级分布、ΔZ 分布、退步/进步/保持全部给出，不只给一个总率。
- **明细下沉**：学生个体明细进附录；正文给分布、标签计数、代表性名单。
- **异常标记**：n<8、缺考、转科、班级重组、回退原始分，必须在表内可见。
- **口径一致**：同一数字在正文、附录、旧报告（可比部分）必须一致。

## 6. 解读与归因规则

### 6.1 好/差/无显著变化

以**平均 ΔZ** 为主效应量（不是退步面）：

| 平均 ΔZ | 表述 | 条件 |
|---|---|---|
| ≥ +0.30 | 明显高于基准 | n≥8 |
| +0.10 ~ +0.30 | 略高于基准 | n≥8 |
| −0.10 ~ +0.10 | 基本持平 | n≥8 |
| −0.30 ~ −0.10 | 略低于基准 | n≥8 |
| ≤ −0.30 | 明显低于基准 | n≥8 |
| n<8 | 样本不足 | 不判定 |

退步面作为第二镜头：实际 vs 基线 31.7% vs 按本单位分布推算的期望；差值 <2pp 视为“接近期望”。

### 6.2 归因分级

- **L1**：哪个入口段/班/科/学生群；可由数据直接证明。
- **L2**：机制候选；需排除入口结构、班级重组、样本、指标效应。
- **L3**：教学/管理/制度；只写“候选/待验证”，并列出需要什么数据。

### 6.3 三条红线

1. 不把相关当因果；
2. 不把结构当教学；
3. 不把小样本当趋势。

### 6.4 跟进分档与行动分层（v1.1）

**每个单位都要有归宿，但不是每个单位都写一段话。** 行动分三层：

| 层 | 位置 | 覆盖 | 作用 |
|---|---|---|---|
| 1 单元跟进 | D.1 末（学科）、D.2 末（班级） | 全部学科、全部班级 | 每行给“跟进档 / 归口 / 两周动作 / D+14 复查” |
| 2 重点行动 | F.3 开头 | 3–5 条 | 只给“重点”档，写谁做什么、何时到人 |
| 3 组合格 | F.1 | 掉2档 ≥8 人的班×科，前 10 | 把“班×科”集中点变成可核对的清单 |

跟进分档以平均 ΔZ 为主镜头（与 6.1 的 5 档判定一一对应，但合并表述）：

| 平均 ΔZ | 跟进档 | 归口 | 两周动作 |
|---|---|---|---|
| ≤ −0.10 | 重点 | 年级组 + 备课组（班：+班主任） | 同题分析 + 分层作业；班按掉档最多的 2 科拆解并核对名单 |
| −0.10 ~ +0.10 | 观察 | 备课组（班：班主任） | 只记录；下次考试再判 |
| +0.10 ~ +0.30 | 保持 | 备课组（班：班主任） | 记录做法，不加码 |
| ≥ +0.30 | 可复制 | 教研组（班：年级组） | 出一页可复制做法，跨科/跨班分享 |
| n<8 | 不判定 | — | 不进排名，下次再看 |

- 分档只用于排序与归口，不等于教学评价；归口是建议，不是问责。
- 行动不能只在“均值最低的 3 个单元”里挑：均值持平但退步面高于期望、或掉档人次集中的班×科，必须在第 3 层出现。
- “复查”只写一次（F.3 的 D+14），各章不再重复“两周后看什么”。
- 目标反推只在 rate < 1.0 时给“回保持”人数；rate 已高于 1.0 的单位改为“维持 ≥1.0”，不设倒挂目标。

## 7. 新入口与路由

```
评价任务列表
└─ 查看结果 | 查看报告（旧） | 分析报告（新）
                                └─ #/evaluations/:id/analysis（中心）
```

- 管理员可切换学校；学校管理员固定本校；
- 新入口先对管理员开放，验证后放开学校管理员。

## 8. 完整版与简易版

### 完整版（当前阶段）

- A–F + 附录；
- 正文 12–18 页，附录不限；
- 每章首屏 = 一句话 + 3 个数 + 1 个动作 + 置信度（供抽取）。

### 简易版（后续）

- 封面 + A 的精简版 + B + F + 每角色 3–5 个“结论卡”；
- 结论卡从完整版每章首屏抽取，不另写；
- 保持同一数据源、同一结果版本。

## 10. 验收

1. 每个数字与结果版本一致，旧报告可比部分一致；
2. 每章有完整单位/分布，不遗漏、不挑选；
3. 每章有好/差/无显著变化三向解读；
4. 每个“为什么”有证据、有反证、有边界；
5. 新版入口为唯一分析入口，旧报告入口已关闭；
6. 校长版在 1440×1000 与 1280 宽下可读，打印不截断。

## 11. 当前实现（阶段三）

- 入口：评价任务列表 → 每个已完成任务新增“分析报告 新” → 分析报告中心 → 七个角色；
- 路由：`#/evaluations/:id/analysis`（中心）、`#/evaluations/:id/analysis/:role`（角色）；
- 文件：
  - `assets/js/core/analysis-metrics.js`：派生层（平均 ΔZ、期望退步面、班级号变化、风险标签、矩阵）；
  - `assets/js/pages/analysis.js`：中心页、校长 A–F + 附录；
  - `assets/css/analysis.css`：新版式与打印；
  - `evaluations.js` 仅新增路由分支与列表入口，旧报告 `reports.js` 未改；
- 数据：只读 `App.result(task.id)`，不重新计算，不回写旧数据层；
- 打印：A–F + 单位附表进 PDF；学生全表（748 行）屏幕可查并支持 CSV 导出，打印版用提示替代，避免 PDF 过长；
- 当前已验证：管理员/学校管理员视图、旧报告入口关闭（直连显示关闭页）、1440/1280 无页面横向溢出、控制台 0 错误。

### 11.1 行动与复查（2026-10-26 升级）

- **目标反推**：把“当前退步中最浅的学生逐步改为保持”，估算达到目标 rate 需要多少人；例：全校 0.91→0.95 需 19 人，1班总分 0.28→0.40 需 4 人，1班数学 0.24→0.40 需 9 人（现有掉 1 档 9 人）。
- **两周执行协议**：D0–D2 锁名单（班主任+科任）、D+3 十题小测+错因表（备课组长）、D+4–D+10 两次分层课/作业+谈话（科任+班主任）、D+14 同结构复查（年级主任）。
- **验收规则**：回保持人数 ≥ 目标人数的 50% 为有效；<50% 换方法；缺课优先处理；不以一次考试定论。
- **入口段双向**：同一段同时给进步/退步的人数、段内占比、同段基准与差；E/D4 共用。
- **班级表汇总**：D2 班级表、A3 班级全表、E 班×科矩阵末行加“整体汇总”；矩阵汇总标注“人次”，避免与去重人数混淆。
- **教师表拆分**：D3 用一张“教师明细”表，学科/教师列合并单元格；每位教师先列“教师汇总”，再列所教班级；单班教师只留一行并标注“仅1个班”；当前 62 位教师、122 个教师×班级组合，其中 51 位跨多个班；不把班间差异直接归因教师。

### 11.4 正向标签与尖子生（2026-10-26）

- D4 标签改为“负向 + 正向”全员口径：负向 4 类、正向 5 类；另列“正向样本：总分升2档以上（43人）”。
- 其他模块补正向：D1/D2/D3 增加“进步面”，B 四校总表增加“进步面”，C 流动摘要增加升档/保持/降档总量，E 已有进步差/退步差。
- 新增“尖子生池监控（入口 G1–G2）”：入口 49、当前 47、留存 28、掉出 21、新进 19；看流向、班级集中、学科短板；预警为“任一科≤G4 或 ΔZ<−0.25”，连续两次规则从下一次考试累计。
- 标签口径：负向/正向均按全员 748 统计，可多标签重叠；KPI“优先跟进 181”是负向并集，不等于表内相加。
- D4 同时保留“负向样本：优先跟进（181人）”和“正向样本：总分升2档以上（43人）”，两者不是互斥分组，同一学生可同时命中；完整清单看 A5。
- A5 学生全表与 CSV 同时给“负向标签 / 正向标签”两列，正负可同时命中；D4 的“正向样本”只是正向子集，完整清单仍看 A5。
- 目标反推是“换算”，不是预测或因果承诺；各章“下一步”指向 F 的执行协议。

### 11.2 字号与滚动（2026-10-26 调整）

- 整个原型字体统一放大 **30%**（CSS `font-size` 与少量内联字号改为 `calc(原值 * 1.3)`）；
- 报告内数据表取消所有内部滚动，教师 62 行、学生 748 行直接展开，只保留浏览器页面滚动；
- 1440/1280 无横向页面溢出，`badScrollCount=0`；
- 因全量展开 + 字号放大，页面与 PDF 变长（校长版约 80,000px、打印约 39 页）；页预算 14–18 页作为“目标值”，当前全量版会超过。
- 旧报告页面同步字号放大，但内部滚动行为未改。

### 11.3 用词（2026-10-26 调整）

- 描述现象：用“高于基准 / 低于基准 / 偏离 / 变化 / 集中”，不用“怀疑 / 拖累 / 问责 / 问题 / 异常 / 低值 / 需重点关注”；
- 描述原因：用“候选 / 待核对 / 先核对”，不直接写“是谁的问题”；
- 指标名保留：退步、退步面、低于基准是口径定义，不当作评价词；
- 新版报告文案已全量检索并替换；旧报告保留原稿，未改。

### 11.5 角色接入（2026-10-26）

- **区域/联考**：不做四校合并总体；B 四校各自 KPI + 四校表 + 散点，C 四校各自等级分布 + 结构净变化，D 学校×学科 + 各校最高/最低学科 + 校际极差，E 四校指标差，F 区域行动；无选择器；对区域管理员与校长开放。
- **年级主任**：复用 A–F + 附录完整骨架，范围固定为本校高三年级；数据口径与校长版一致。
- **学科组长**：学科选择器（默认低于基准的学科）；A/B/C、D1 班级、D2 教师、D3 学生正负样本、E/F。
- **班主任**：班级选择器（默认低于基准的班级）；A/B/C、D1 学科、D2 本班学生、E/F。
- **科任教师**：教师选择器（默认有效样本中低于基准的教师）；A/B/C、D1 所教班、D2 学生、E/F；不排名。
- **学生**：学生选择器；A/B 个人位置、C 六科、D 强弱科、E 解释、F 行动；不评价个人能力。
- **状态**：`analysisSubject`、`analysisClassId`、`analysisTeacherName`、`analysisStudentId`；选择后重渲染，学校切换时非法值回退到默认。
- **登录默认**：运营管理员仍进基础数据；学校管理员默认进“评价任务”（`#/evaluations`），不再默认进考试管理。
- **验证**：七角色路由均可打开；选择器切换标题/数据更新；1440/1280 无页面横向溢出、无内部滚动条、0 控制台错误。
- **丰富度（2026-10-26）**：学科增加班级散点、ΔZ 分布、入口段、标签概况；班主任增加 ΔZ 分布、学科条形、入口段、标签；科任增加 ΔZ 分布、所教班条形、入口段、标签；学生增加六科条形、个人/班均/校均对照、标签；区域增加四校散点、结构净变化、校际学科极差；年级保留完整 A–F。

### 11.16 总览补「班级增值总览」（2026-10-27，同日撤销）

**问题（结构性，不是漏了一张表）**：

1. **B 总体的定位偏了**：B 被写成“本校 vs 四校”的对外比较页（KPI + 四校排名 + ΔZ 分布 + 四校总表），回答的是“我校在联考里怎么样”，没有回答“我校 12/18 个班各自怎么样”。校内班级维度的总表因此没有落点。
2. **分章按“单位类型”切，而不是按“读者的一屏决策”切**：学科在 D.1、班级在 D.2、教师在 D.3；班级 × 学科的唯一汇总入口被放进 D.2，排在学科跟进清单之后（学校版第 10–13 页），读者必须先知道“去 D.2 找”，才能看到全校班级名次。

4. **总览页预算把汇总表挡在外面**：B 章按 1–2 页设计，新增班级总表被默认视为“D.2 的职责”，于是“先总后分”只落实在章节顺序上，没有落实在“单位 × 指标”的总表上。

**做法**：

- **B.1 KPI 之后新增「班级增值总览（总分 + 各科排名，N 个班）」**：行=本校全部班级，按总分增值排名升序；列=班级、人数、总分、各科；格内上=校内同科排名（`classEval[科目].rateRank`，n≥8），下=相对进步率（1.0 平衡、无上界）；前三绿、后三红；未选该科或 n<8 显示“—”。
- 表格整块保页（`data-keep`）；班级数 >18 时压缩行高（`.an-rank-compact`），保证 KPI + 19 行同页。
- **D.2 保留班级顺序的明细表**（「班级增值排名」「班级相对进步率」），与 B 表互指：B 表看名次与增值，D.2 看班级顺序、跟进清单与数值明细。
- **目录回 2 页**：新增 B.1 三级条目后，学校版目录溢出到第 3 页（只剩 A7 一行）；把 l1/l2/l3 间距从 5/1.2/0.8mm 收到 4.5/1/0.4mm。
