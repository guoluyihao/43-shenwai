## 1. 术语

| 术语 | 含义 |
|---|---|
| 学校 | 参与评价的独立单位 |
| 年级 | 学校内的一届学生，如“2026 届高三” |
| 年级版本 | 某个学校某个年级在某一时点的基础数据快照，如“分班后 v1”“高三调整后 v2” |
| 班级 | 年级下的行政班 |
| 班主任 | 班级的第一责任人，一名教师 |
| 科任老师 | 在某个班级任教某个科目的教师 |
| 教师 | 学校级教师库中的成员，单列维护 |
| 联考 | 一场包含多所学校的统一考试 |
| 考试 | 一次具体的考试活动，包含名称、时间、参与学校、年级、版本、科目 |
| 成绩单 | 只包含学生成绩的 Excel/CSV 文件 |
| 原始分 | 卷面分 |
| 高考赋分 | 原始分按新高考规则转换后的分数，由外部提供 |
| 计算基础值 | 本次评价使用的分值口径：原始分或高考赋分 |
| 评价任务 | 一次完整的增值评价，包含入口考试、评价考试、按校版本、算法与结果 |
| 联考全体 | 本次评价所有参与学校、所有匹配成功的学生 |
| 学生结果 | 学生维度的增值结果 |
| 班级结果 | 班级维度的汇总结果 |
| 教师结果 | 教师维度的汇总结果 |
| 学校结果 | 学校维度的汇总结果，指标与班级结果一致 |

> 本文件中“赋分”一律指**高考赋分**，不是系统内部生成的分数。

## 2. 产品定位与本期范围

### 2.1 定位

面向多所学校联考场景的成绩增值评价工具：

1. 维护学校、年级、班级、学生、教师、任课与版本。
2. 以“联考”为单位录入成绩，只导成绩单。
3. 以评价任务组合入口考试与评价考试，按学校选择版本。
4. 按联考全体统一计算增值，输出学生、班级、教师、学校四层结果。

### 2.2 本期目标

- 基础数据可维护、可版本化、可追溯。
- 联考成绩可多次导入、覆盖旧数据、保留导入记录。
- 评价任务可跨校组合，按校选版本。
- 四层结果可查看、可筛选、可导出。

### 2.3 本期不做

- 工作台。
- 独立版本管理菜单。
- 独立导入记录菜单。
- 独立结果菜单。
- 图表、报告解读、教师看板、学生矩阵。
- 多次考试趋势、AI 报告、自定义算法。
- 历史数据迁移。

```

├── 学校管理（系统管理员）
├── 基础数据
│   ├── 年级 → 班级 → 学生 / 班主任 / 科任老师
│   ├── 教师（单列）
│   ├── 科目
│   └── 年级版本（在年级详情内）

│   ├── 新增考试

    ├── 任务列表
```

## 5. 基础数据

### 5.1 学校

| 字段 | 规则 |
|---|---|
| 学校名称 | 必填，全局唯一 |
| 学校编码 | 必填，全局唯一 |
| 管理员账号 | 必填，绑定学校管理员 |
| 状态 | 启用 / 停用 |
| 城市 | 可空 |

### 5.2 年级

| 字段 | 规则 |
|---|---|
| 年级名称 | 如“2026 届高三”，同校唯一 |
| 学段 | 高中 / 初中 |
| 入学年份 | 必填 |
| 状态 | 在读 / 已毕业 |

- 年级属于学校。
- 年级下有班级、学生、版本。

### 5.3 年级版本

| 字段 | 规则 |
|---|---|
| 版本号 | 自动生成，如 v1、v2 |
| 版本名称 | 必填，如“分班后”“高三调整后” |
| 状态 | 草稿 / 已发布 / 已停用 |
| 发布时间 / 发布人 | 系统记录 |
| 变更说明 | 必填 |

规则：

1. 版本属于“学校 + 年级”，不是独立模块。
2. 发布即快照，发布后只读。
3. 评价任务按学校选择对应年级版本。
4. 旧版本停用后，历史任务仍可查看。
5. 同一学校同一时间只允许一个“当前版本”。

### 5.4 班级

| 字段 | 规则 |
|---|---|
| 班级名称 | 如“高三(1)班”，同一学校同一年级内唯一 |
| 所属年级 | 必填 |
| 班主任 | 必填，一名教师 |
| 学生数 | 统计值 |

- 班级详情展示：学生名单、班主任、各科科任老师。

### 5.5 学生

| 字段 | 规则 |
|---|---|
| 学籍号 | 必填，全局唯一，匹配主键 |
| 姓名 | 必填 |
| 学校 / 年级 / 班级 | 必填 |
| 选科组合 | 必填，3+1+2 |
| 状态 | 在读 / 转学 / 休学 / 毕业 |

### 5.6 教师

| 字段 | 规则 |
|---|---|
| 工号 | 必填，全局唯一 |
| 姓名 | 必填 |
| 学校 | 必填 |
| 任教学科 | 必填 |
| 是否班主任 | 由班级关系决定 |
| 状态 | 在职 / 离职 |

- 教师在学校级单列，不在班级里重复维护。
- 班级通过“班主任”和“科任关系”引用教师。

### 5.7 任课与班主任

| 关系 | 规则 |
|---|---|
| 班主任 | 班级属性，一名教师 |
| 科任老师 | 教师 × 班级 × 科目；同一班级同一科目可多名，需标记主责 |
| 教师评价归属 | 默认按主责教师；无主责时按全部任课教师并提示 |

### 5.8 科目

| 字段 | 规则 |
|---|---|
| 科目名称 | 同校唯一 |
| 类型 | 必考 / 首选 / 再选 |
| 计分方式 | 原始分 / 等级赋分 |
| 满分 | 必考 150，选考 100 |
| 排序 | 决定结果表与导出顺序 |
| 是否计入总分 | 是 / 否 |

## 6. 考试管理

### 6.1 考试（联考）

| 字段 | 规则 |
|---|---|
| 考试名称 | 必填 |
| 考试时间 | 必填 |
| 参与学校 | 可多选 |
| 每校参与年级 | 按学校选择 |
| 每校基础数据版本 | 按学校选择对应年级版本 |
| 参与科目 | 多选 |
| 状态 | 草稿 / 已发布 |

规则：

- 一场考试可以包含多所学校（联考）。
- 每所学校使用自己的年级与版本。
- 考试发布后才可被评价任务引用。
- 成绩导入前必须先完成考试配置。

### 6.2 新增考试

流程：

1. 填写考试名称、考试时间。
2. 选择参与学校（可多选）。
3. 对每所学校选择参与年级与基础数据版本。
4. 选择参与科目。
5. 保存后进入考试详情，上传成绩单。

### 6.3 成绩单导入

- 只上传**成绩单**，不需要学生名册、教师名单、任课表。
- 文件类型：Excel（.xlsx/.xls）与 CSV。
- 流程：上传 → AI 解析 → 与考试/学校/年级/版本匹配 → 差异确认 → 入库。
- 一个导入任务可包含多所学校的成绩文件。
- **同一考试同一时间只允许一个导入任务**。
- **按学校覆盖**：本次导入涉及哪所学校，就替换该校旧成绩；未涉及学校保持不变。
- 入库后只保存成绩，**不做平均分、排名、统计、分析**。
- 导入记录保存在考试详情内，不单独设菜单。

### 6.4 导入差异

| 级别 | 示例 | 处理 |
|---|---|---|
| 阻断 | 无法识别学生、重复记录、分数越界、文件损坏 | 必须逐条处理，清零后才能入库 |
| 待确认 | 新增学生、缺失学生、班级变更、选科变更、赋分缺失 | 逐条或批量确认 |
| 提示 | 低置信度字段、科目别名、格式不统一 | 可批量接受 |

### 6.5 考试详情

展示：

- 考试基本信息：名称、时间、参与学校、年级、版本、科目。
- 成绩列表：学校、班级、学号、姓名、科目、原始分、高考赋分。
- 导入记录：批次、文件、学校、时间、成功/跳过/失败、差异处理。
- 操作：上传/重新导入、删除考试。

### 6.6 删除考试

- 支持删除考试。
- 已产生评价任务的考试禁止删除，提示先删除关联评价任务。

### 6.7 成绩字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 学校 | 是 | 联考中的参与学校 |
| 学生 | 是 | 必须属于该校所选年级 |
| 科目 | 是 | 必须在考试科目范围内 |
| 原始分 | 是 | 0 ~ 满分 |
| 高考赋分 | 否 | 外部提供；无则为空 |
| 缺考标记 | 是 | 正常 / 缺考 / 免考 |

### 6.8 赋分规则

1. 高考赋分由外部提供，系统不计算。
2. 有就存，没有就留空。
3. 评价时由任务配置决定是否使用赋分。
4. 赋分缺失的科目整科回退原始分，并在结果中标注。

## 7. 评价任务

### 7.1 新建与配置

| 配置项 | 规则 |
|---|---|
| 任务名称 | 必填 |
| 入口考试 | 必填，已发布 |
| 评价考试 | 必填，已发布 |
| 参与学校 | 默认取两次考试共同参与的学校 |
| 每校版本 | 默认取评价考试配置的版本，可覆盖 |
| 评价范围 | 学校 / 年级 / 班级 / 科目 |
| 计算基础值 | 任务默认 + 科目覆盖 |
| 算法 | 标准分增值法 / 等级差法 |
| 参数 | 等级档数、阈值、步长、小样本阈值 |

### 7.2 按学校选版本

- 联考包含多所学校时，逐校选择对应年级版本。
- 默认使用评价考试中该校配置的版本。
- 入口考试版本不一致时，进入异常清单，人工确认。
- 版本决定班级、学生、班主任、科任老师的归属。

### 7.3 计算基础值

- 任务级默认：原始分 / 高考赋分。
- 科目级覆盖：可逐科指定。
- 默认按科目计分方式带出。
- 同一科目同一任务只能一种口径。
- 赋分缺失时整科回退原始分并提示。
- 结果表必须标注本次口径。

### 7.4 匹配

- 学生：学籍号优先，身份证号兜底，姓名+班级辅助。
- 学校：按考试参与学校匹配。
- 班级、科目、教师：按版本与任课关系匹配。
- 两场考试参与学校不一致时，只计算共同参与学校；单边学校进入异常清单。
- 阻断项清零后才能进入算法。

### 7.5 任务状态

草稿 → 待匹配 → 匹配待确认 → 待计算 → 计算中 → 已完成 / 失败。

## 8. 多校联考算法

### 8.1 统计总体

- 每个科目以**联考全体参与学生**为统计总体。
- 总分按“首选科目”分组（物理类 / 历史类），同样在联考全体内计算。
- 单校评价是多校的特例。

### 8.2 学生结果

1. 计算联考全体某科目均值、标准差。
2. 标准分 =（本人分数 − 均值）÷ 标准差。
3. 按联考全体百分位划分等级。
4. 比较入口与评价考试标准分变化，判定进退步。
5. 等级差法直接比较入口等级与评价等级。

### 8.3 四层汇总

| 层级 | 分组 | 指标 |
|---|---|---|
| 学生 | 学生 × 科目/总分 | 标准分、等级、进退步 |
| 班级 | 学校 + 班级 + 科目/总分 | 与班级指标一致 |
| 教师 | 学校 + 教师 + 科目/总分 | 与班级指标一致 |
| 学校 | 学校 + 科目/总分 | **与班级指标完全一致** |

学校结果指标：

- 学业实力
- 保持值
- 进步值
- 退步值
- 相对进步率
- 平均进退步级数
- 进步学生占比 / 退步学生占比
- 实力排名
- 进步率排名

### 8.4 排名范围

| 对象 | 范围 |
|---|---|
| 学生 | 联考全体同科目 |
| 班级 | 校内同科目 |
| 教师 | 校内同科目 |
| 学校 | 联考全体同科目 |

### 8.5 指标公式

| 指标 | 口径 |
|---|---|
| 学业实力 | Σ（本次各等级人数占比 × 等级权重） |
| 保持值 | Σ（保持学生入口等级权重 − 10）÷ 人数 |
| 进步值 | Σ（进步学生从入口等级向上跨级的权重）÷ 人数 |
| 退步值 | Σ（退步学生从入口等级向下跨级的 100 − 权重）÷ 人数 |
| 相对进步率 | （保持值 + 进步值 × 2）÷（（退步值 + 1）× 1.5） |
| 平均进退步 | Σ 级数 ÷ 人数 |
| 进步占比 | 进步人数 ÷ 人数 |

### 8.6 边界

| 场景 | 处理 |
|---|---|
| 全员同分 | 标准分为 0，全部保持 |
| 组内 1 人 | 样本不足，不排名 |
| 缺考 | 不参与该科计算 |
| 赋分缺失 | 整科回退原始分并标注 |
| 学校单边参与 | 只算共同学校，单边进异常 |
| 班级/教师样本不足 | 不参与排名，标注 |
| 选科变化 | 涉及科目不可比，按异常处理 |

## 9. 结果呈现

### 9.1 入口

- 只能从评价任务详情进入。
- 四个 Tab：学生结果、班级结果、教师结果、学校结果。
- 第一版只做表格、筛选、分页、导出。

### 9.2 学生结果

字段：

- 学号、姓名、学校、班级
- 科目 / 总分
- 入口值、评价值
- 入口等级、评价等级、等级变化
- 进退步、进退步级数

默认一行一个学生（总分），可切换科目查看单科。

### 9.3 班级结果

字段：

- 学校、班级、人数
- 学业实力、保持值、进步值、退步值、相对进步率
- 平均进退步、进步占比、退步占比
- 实力排名（校内）、进步率排名（校内）

### 9.4 教师结果

字段：

- 学校、教师、科目、任教班级、人数
- 学业实力、相对进步率、平均进退步、进步占比
- 实力排名（校内）、进步率排名（校内）

### 9.5 学校结果

字段与班级结果一致：

- 学校、人数
- 学业实力、保持值、进步值、退步值、相对进步率
- 平均进退步、进步占比、退步占比
- 实力排名（联考）、进步率排名（联考）

## 10. 业务规则

| 编号 | 规则 |
|---|---|
| R01 | 基础数据按“学校→年级→班级”组织，版本跟年级走 |
| R02 | 年级版本发布后只读，修改需发新版本 |
| R03 | 教师在学校级单列，班级通过班主任/科任关系引用 |
| R04 | 考试可包含多所学校，每校配置年级与版本 |
| R05 | 考试只导成绩单，不导其他文档 |
| R06 | 同一考试同一时间只允许一个导入任务 |
| R07 | 新导入按学校覆盖旧成绩，未涉及学校不变 |
| R08 | 入库后不做统计与分析 |
| R09 | 已产生评价任务的考试不可删除 |
| R10 | 评价任务按学校选择版本，默认取评价考试版本 |
| R11 | 多校联考按联考全体统一标准化 |
| R12 | 学生按联考排名，班级/教师按校内排名，学校按联考排名 |
| R13 | 学校结果指标与班级结果完全一致 |
| R14 | 第一版只输出四类结果表格，不做图表/报告/看板/矩阵 |
| R15 | 结果只能从评价任务进入 |
| R16 | 学校管理员只读，唯一写操作是修改本人密码 |

## 12. 默认约定

| 事项 | 默认 |
|---|---|
| 等级档数 | 7 档（可选 9 档） |
| 保持阈值 | 0.25 个标准差 |

| 班级/教师排名 | 校内 |
| 学校排名 | 联考全体 |
| 导入文件 | Excel / CSV |
| 导入覆盖 | 按学校 |
| 登录落地页 | 评价任务 |
| 学校管理员 | 只读 |
