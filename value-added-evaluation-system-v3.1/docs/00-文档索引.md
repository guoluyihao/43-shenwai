## 原型

`prototype/` 为 v3.1 可点击原型：首页 `prototype/index.html` 兼登录页，登录后进入系统 `prototype/app.html`。

- 5 个菜单：学校管理、基础数据、考试管理、评价任务、参数配置（仅系统管理员）；帮助区另有算法说明
- 已导入高中园四校基础数据与高二期末/高三两场成绩
- 评价任务已接入：预置 1 个已完成四校联考任务（9 档 / R4），支持新建、配置、匹配、算法、计算与四类结果；任务列表可进入六类角色报告
- 首页登录后进入基础数据
- 数据全部本地预置，不联网；报告为结果只读快照
